  Copyright (c) 2026 ArtCraft Team and the DesignCraft contributors. Full notices are
  retained in `src/frame_compose/LICENSE-{MIT,APACHE}`. The adapted breaker uses native
  cluster advances; source dependencies on its fonts/document/story tree are removed.
  No dictionary/patgen, upstream text stack, branded assets or renderer is imported.
- Native layout oracle: existing `pc-text/src/layout.rs` / parley 0.11 / harfrust 0.12 /
  skrifa 0.44 from Cargo.lock. Existing `pc-text/src/render.rs` supplies rasterization.
- `main.rs`: original Local Image synthetic text fixtures, GPL-3.0-or-later. Exact
  monospace reference: four two-letter words with three spaces; at 5.5 cells the only
  two-line fit without splitting words is `aa aa` / `aa aa`. A 12-cell frame fits all.
  Cells are measured through the bundled font (no system font requirement), 12 pt,
  72 dpi, standard ligatures off. No screenshot golden generated by the implementation.
- Font: bundled JetBrains Mono (existing repository font/licence); mixed Unicode uses
  the existing fallback configuration. The fixtures test cluster/range preservation;
  missing script fonts do not establish typographic quality for those scripts.
- Optical-margin fractions and kinsoku expectations follow the pinned breaker. Baseline
  grids use explicit origin 3 px / spacing 18 px, verified against the arithmetic grid.
  Native default/point/complex-text comparison includes glyph IDs, coordinates, face
  bytes, variation coordinates, styles, clusters, decorations and lines.
- UI fixtures are in the owned `pc-ui-egui/src/vector_packages/frame_compose.rs` test
  module; egui/egui_kittest 0.36 use real pointer/checkbox/keyboard events, no windows.
- `app_gpu.rs` is the package-00 full-app acceptance source. It requires the persisted
  field and actual app hooks specified in integration/30.md; it is deliberately not
  registered as a passing isolated GPU test. Its gate requires RTX 5090, Vulkan,
  discrete device, Rgba32Float accumulation and premultiplied max diff <= 1/255.
- Tools: Rust 1.98.1, cargo offline, CARGO_BUILD_JOBS=3 and the inherited li-rustc-gate.
  No proprietary paragraphs/goldens or external multilingual quality corpus supplied.
