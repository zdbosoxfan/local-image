# Envelope fixtures and oracles

All geometry fixtures are generated by the Rust tests in `geometry.rs` and are
original Local Image test code, GPL-3.0-or-later. No brand, proprietary, downloaded
SVG or external binary corpus is used. Squares, a cubic, an eight-sided outline,
a flat line and normalized grids have explicit coordinates in the tests.

- Warp/grid/Coons reference: VectorCraft `crates/doc/src/live.rs` and
  `crates/effects/src/warp.rs`, verified checkout
  `d522c1d7be4035bd4f4a84cd6ebfca44f5155092`, MIT OR Apache-2.0.
- Fitting reference: cached kurbo **0.13.1** `src/fit.rs`,
  [official API](https://docs.rs/kurbo/0.13.1/kurbo/fn.fit_to_cubic.html),
  MIT OR Apache-2.0. Its numerical distance metric is not a rigorous interval bound.
- Identity checks retain all original coordinates/handles and test Hausdorff <1e-6.
  Affine oracle is a separate explicit normalized affine matrix on every native
  anchor/control. Arch oracle is its analytic parabola. Coons curved top edge is
  a separately calculated cubic/parabola; reversed winding is tested.
- Parameters: source nodes <=8192, output <=min(65536, 32x input), tolerance 0.05
  document pixels by default (allowed 1e-6..10), depth 16 and one million mapped
  samples per evaluation; mesh rows/columns 1..32, normalized coordinates [-16,16].
  General top boundaries flatten at min(0.005px, tolerance/8) with <=16384 samples / depth 24.
  Bounds with a flat axis use a centered one-pixel frame.
- Geometry comparisons use symmetric sampled point-to-polyline distance at 256
  samples per output segment; affine handles are checked directly to 1e-10.
  The nonlinear cubic Arch oracle separately evaluates 512 original-curve samples
  against the analytic parabola and nearest output curves. These oracles differ
  from production fitting and its 65-sample guard.
- Engine/UI fixtures use native pc-text bundled fallback fonts (the repository's
  existing licensed assets) and original strings `ABC O` / `OABC`, visibly red text plus a black
  path on a 192x160 transparent native document. Native tests use `.pcraft` ZIP
  memory round-trips; the existing v1 fixture is loaded without modification.
- Toolchain: Rust/Cargo 1.98.1, egui/egui_kittest 0.36, existing wgpu 30.
  Tests are offline with `PHOTOCRAFT_NO_SYSTEM_FONTS=1` (committed OFL Inter/JetBrains Mono only). No external fixture generator or reference executable ran.
- UI regressions deliver real `WindowFocused(false)` input and type a 4x4 mesh
  before dragging its center handle; the same original document capture must
  survive the numeric preview and publish only one undoable edit.

The native ZIP roundtrip currently fails because the pre-existing shared
`LiveGroup`/`EnvelopeSpec` wire schema uses `kind` twice. The test remains active
and this gate is not counted as passed. The schema-owner fix is supplied in
`docs/wip/vector-tasks/integration/20.md`.

GPU tests require RTX 5090, Vulkan, discrete adapter, Rgba32Float and the app's
float canvas support. They remain ignored integration gates under the owner's
2026-10-10 speed rule. They are supplied, not counted as executed acceptance.
Missing external/proprietary corpus and manual production-router acceptance are
recorded in the report, never counted as passed tests.
