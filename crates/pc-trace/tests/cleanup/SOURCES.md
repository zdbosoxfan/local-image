# Cleanup package 26 fixtures and references

All fixture shapes/pixels in mod.rs are Local Image originals, generated at test time, dedicated to CC0-1.0. Rust generator/tests are GPL-3.0-or-later. No logo brands, external raster files or owner documents are copied. quality.rs and gpu.rs reuse the existing T1 `tests/it/common/mod.rs` synthetic corpus and its clean pc-vector render: circles, rounded rectangle, polygon, arrow, donut, and the OBO outline wordmark from `assets/fonts/Inter-Regular.ttf` (SIL OFL 1.1, `assets/fonts/OFL-Inter.txt`). See `../corpus/SOURCES.md` for its degradations and licenses.

Toolchain: Rust 1.98.1; locked kurbo 0.13.1 (curve approximation/recognition), resvg 0.45.1 (independent supplied-reference rasterization), ttf-parser 0.25 (existing wordmark outline generator), image crate version recorded in Cargo.lock (existing T1 image/degradation helpers). Production adds no dependency. Deterministic tests serialize the complete Output and compare 1/2/4 simultaneous tracing workers. Property tests use 256 generated binary masks, widths/heights 1..8, both colors, exact Pixel fitter, AA palette and collinear cleanup. A persisted proptest failure would be retained rather than hidden.

The focused quality test traces six 256-pixel clean corpus logos with Params::Logo unchanged. It measures each of axes, collinear, right_angles, circles, ellipses, arcs, symmetry, aa_palette, prefilter, small_holes, upscale 2×, upscale 4× and the complete Options::logo request against the **same input with T1/no cleanup**. The combined default's node and fidelity assertions are separate from the per-toggle measurements. It writes `target/cleanup-26/toggles.json`, not a fabricated competitor score file. Standalone preprocessing toggles can have different fidelity tradeoffs; the JSON records them.

Additional fixtures verify analytic circle/rotated ellipse/annulus area and opposite winding, small circles, open/closed semicircle arc Hausdorff, nearly collinear/axis/right-angle paths, white and transparent counters, low-contrast enclosed defects, hidden RGB, ignored white, finite/budget/cancellation behavior and exact .98 mirror rejection. Geometry metrics use pc-testkit's independent area/Hausdorff/intersection oracles. T1 can have a tiny cusp below its coarse topology guard: single-toggle tests only allow inheritance if the complete offending path is byte-identical to T1. The combined Logo output cannot inherit such crossings.

Sources followed:
- VectorCraft `crates/geom/src/recognize.rs` at **d522c1d7be4035bd4f4a84cd6ebfca44f5155092**, verified in the local sampled checkout. MIT OR Apache-2.0; upstream copyright/SPDX preserved in the adapted recognition file. One exact PORTS row is handed to 00 in integration/26.md.
- Existing pinned vtracer Oklab palette code (`pc-trace/src/colorfit/oklab.rs`, vtracer 928ed0a6f654408e28fb741b6133d4c456bd0160) reused directly.
- [Tomasi–Manduchi, Bilateral Filtering for Gray and Color Images, ICCV 1998](https://doi.org/10.1109/ICCV.1998.710815), algorithm reference only; original bounded 5×5 Rust kernel. The guided-filter alternative was not copied, so no darktable/lc-pipeline dependency or new license port is needed.
- [scikit-image 0.26.0 find_contours documentation](https://scikit-image.org/docs/0.26.x/api/skimage.measure.html#skimage.measure.find_contours): linear marching-square interpolation, high pixels 4-connected at ambiguous diagonal contacts and pixel-centre coordinate convention. Original Rust contour implementation; no upstream source is copied.
- kurbo 0.13.1 local locked sources `arc.rs`, `simplify.rs`, `bezpath.rs` and param-curve/extrema APIs. Potrace's calc_lon requires unit lattice steps: the AA fractional path uses kurbo's optimal simplifier **inside cleanup**, leaving the T1 fitter implementation intact.

Missing corpus/reference assets remain missing: no 15 external CC0/PD SVGs, no five licensed scans, no complete vtracer 1.0.0-alpha.4/0.6.5 or Potrace 1.16 SVG/score suite was supplied. `cleanup_full_competitor_gate` fails explicitly without them. Synthetic tests, missing gates and ignored tests must be reported separately. GPU gate requires RTX 5090/Vulkan/discrete/Rgba32Float; software/no-adapter is an error, not a skip.
