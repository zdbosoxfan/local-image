The two XMP Hooks in engine/UI unit fixtures are a deliberately visible **synthetic test
adapter** to test provider atomicity/history. They are not a native adapter or persistence
acceptance. The separate ignored native gate must be exercised with actual shared fields.
GPU ignored gates are not counted as passes. No external/proprietary corpus is required for
these original rect/text fixtures; no missing-font CJK result or missing corpus is claimed.
Bundled Latin pc-text fallback is used; the build's missing craft-fonts warning is recorded.
