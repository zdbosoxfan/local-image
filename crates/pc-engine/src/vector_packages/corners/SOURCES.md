# Corner fixtures and independent oracles

All fixtures are generated by `tests.rs`, `gpu_tests.rs`, and the package's UI tests. They
are original Local Image GPL-3.0-or-later geometry, contain no brand assets, and use no
proprietary/owner/external corpus. No missing corpus is counted as a passed gate.

- Square: `(8,8)` to `(108,108)`, side 100 document pixels; radii 0, 1, 10, 20, 49, 50,
  80 and 1e6; all four kinds. The independent area oracle integrates the cubic polynomials
  using Green's theorem. Rounded-square allowance: `2e-8*r² + 1e-8` square pixels.
  Chamfer is tested against `s²-2r²`; Inverted against `s²-pi*r²`; Straight retains `s²`.
- Curved adjacency: the same square with the top/right incident cubic handles moved inward;
  round, scallop and chamfer at low/intermediate/oversized radii. Independent dense uniform
  cubic sampling detects proper segment crossings. A separate circularity/tangency oracle
  reconstructs the fillet centre from its endpoint tangent and checks its radial distance.
- Seeded area properties: 256 rectangles of width/height 20..200, arbitrary rotation and
  translation, seed `0x06c01234`, LCG multiplier 6364136223846793005/increment 1. Ground truth
  is analytic rectangle/circle area, independent of the evaluator's subdivision/trim solver.
- Degeneracies: open endpoints, smooth nodes, singleton path, collinear/folded segments,
  bow-tie contour, duplicate/invalid base indices, NaN/infinity, numeric/complexity budgets.
- Compound: joined hole subpath, EvenOdd fill and inversion metadata retained unchanged.
- Remapping: own explicit deletion/reorder/subpath maps, never projected knot indices.
- Persistence: existing committed `pc-format/tests/fixtures/vector-v1.pcraft` from the vector
  foundations, plus generated native ZIP bytes with corners. No extension field is required
  by the legacy fixture. The persistence test also covers exact base path and undo/redo.
- GPU: generated 5-point star in `[14,14,100,100]`, inner ratio 0.45, radius 12 Round; generated
  square with radius 12 Inverted, 128x128 RGB/F32, solid `(0.2,0.5,0.8,0.7)`. Compositor checks
  every premultiplied pixel against CPU and assert max diff <= 1/255.
- Full app GPU: 128x128 RGB/F32 with white background and a generated star or square; solid
  `(0.16,0.47,0.82,0.7)`. Actual egui press/move/release (drag delta `16*(u+v)` screen pixels, all corners), app canvas render, aligned 1x source
  pixels. Hide handles through the app's Extras visibility and compare all 12,544 interior
  pixels, including every corner boundary. Held preview, release, cancellation and undo are checked.
  The isolated compositor gate includes all pixels and transparency, without widget exclusion.

- VectorCraft `d522c1d7be4035bd4f4a84cd6ebfca44f5155092`, MIT OR Apache-2.0,
  [geom/corners.rs](https://github.com/storytold/vectorcraft/blob/d522c1d7be4035bd4f4a84cd6ebfca44f5155092/crates/geom/src/corners.rs)
  and [tools/corners.rs](https://github.com/storytold/vectorcraft/blob/d522c1d7be4035bd4f4a84cd6ebfca44f5155092/crates/tools/src/corners.rs).
  Verified the local checkout at that pin. Contrary to the older quality-plan description,
  this upstream module explicitly excludes curved incident edges; the bounded offset-root
  solver and static curve safety cap are Local Image extensions, not claimed upstream ports.
- [Affinity Corner Tool](https://affinity.help/designer2/en-US.lproj/pages/Tools/tools_corner.html),
  read 2026-10-10. Drag inward to increase radius, context kind/radius controls, reversible
  live appearance. The data boundary's Straight means sharp/None; Chamfer is its straight cut.
- Native cubic/control interpretation: existing `pc-doc/src/vector.rs`, `pc-vector` flatten,
  CompiledShape and sparse Surface API. Offset curves are solved in the half-edge domains,
  followed by de Casteljau trimming and <=11.25-degree cubic circular arcs.
- Existing full-app offscreen harness: `pc-ui-egui/tests/gpu/move_canvas.rs`; egui_kittest 0.36.2,
  egui/eframe 0.36.2 and wgpu 30.0.1 cached official Rust sources. Strict adapter/float checks
  are added for this gate, replacing any legacy optional/skip convention.
