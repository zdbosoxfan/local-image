# SVG import fixture sources

All tests are offline. No brand assets or owner files are included.

The 15 SVGs directly in this directory and `expected-trees.json` are original,
small geometric fixtures authored for Local Image on 2026-10-10 and dedicated
to CC0-1.0. Their document sizes, positions, fonts, colours and transforms are
literal in the XML; no external tool generated their paths. Twelve geometry/paint
fixtures additionally compare
against fresh resvg 0.45.1 renders at 8x, box-integrated in premultiplied colour,
with alpha-area IoU >=0.97 and RGB MAE <=0.02. The two gradient fixtures also
require off-edge Oklab delta E mean <0.5 and max <2, using pc-testkit metrics.
The one-pixel PNG in embedded-image.svg is an original opaque red RGBA8 sample
(PNG/zlib).
Editable text uses the project's bundled Inter font; no system fonts are loaded.
The embedded image has independent literal RGBA/placement checks: our locked
resvg has raster-images disabled and enabling it would introduce new gif/zune
versions. That unrun reference feature is not counted as a passed gate.

`resvg/` contains 400 unchanged SVG/reference PNG pairs from
[linebender/resvg](https://github.com/linebender/resvg/tree/1b6c2fddbcbeffa8135df4323b02aaae84890907/crates/resvg/tests/tests),
commit `1b6c2fddbcbeffa8135df4323b02aaae84890907` (v0.45.1), MIT OR Apache-2.0.
Both upstream license files are retained. `resvg/cases.tsv` records every
upstream relative filename and SHA-256 for both files.

Selection was fixed before scoring: sorted UTF-8 SVGs below 50 KB with paired
PNGs, excluding text, image, DTD, pattern, filter and script elements; evenly
spaced picks within each family: shapes 90, painting 130, structure 90,
paint-servers 65, masking 25. This deliberately scopes the gate to normalized
geometry/paint, with text and embedded images covered by the original fixtures.
It is not a claim that all upstream SVG features pass. Tests use 96 DPI and
the upstream documented 300px output width, native pc-vector exact-area coverage
and the ordinary
pc-compose compositor. Root viewport dimensions are resized through the original
viewBox (or its resolved viewport when absent); root opacity, backgrounds and
namespace prefixes remain intact. The SVG and PNG fixture bytes stay unchanged.
Per-case gates: alpha-area IoU >=0.97 and premultiplied
sRGB channel mean absolute error <=0.02. The remaining deviations are named in
`resvg/ratchet.tsv`; a new failure or pass rate below 90% fails the test.
Reference PNGs are upstream committed artifacts, not regenerated by our importer.

`external/` contains 40 unchanged non-brand Lucide icons from
[lucide-icons/lucide](https://github.com/lucide-icons/lucide/tree/f12b0de177fbc2a6795e99be065887e72b237123/icons),
commit `f12b0de177fbc2a6795e99be065887e72b237123` (0.468.0), ISC; copyright
and the upstream license are retained in `external/LICENSE`. `cases.tsv` lists
each filename and SHA-256. These test import success/no panics, not render
fidelity. Five supplemental public-domain maps/illustrations are in `external/commons/`;
their unchanged bytes, SHA-256, authors, license and URLs are recorded there.
This broader stress sample is a no-panic gate with successful imports and bounded
rejections reported separately. Proprietary owner exports are unavailable and
do not count as passed gates.

Toolchain: Rust 1.98.1, usvg/resvg 0.45.1, svgtypes 0.15.3, roxmltree 0.20.0.
Archives were retrieved during fixture preparation, never by a test.
