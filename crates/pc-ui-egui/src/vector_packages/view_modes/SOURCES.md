## Fixtures (all generated by tests, GPL-3.0-or-later)

- Vector column profile: vertical x=24.5 device line, document y=1..7, scale=1/8;
  exact independent oracle one opaque column at x=24, all others transparent.
- Overlap: rectangles at (5.5,5.5) and (10.5,10.5), size 20x20; click (25.5,18)
  lies in the top fill and on the bottom path. Opaque red fills, 6px original strokes.
- Open elbow: (4,4)->(24,4)->(24,24); hit on hypothetical fill closing diagonal must fail.
- Raster cross: own surface bounds (2,2)-(12,12); box plus two diagonals, exact same-clip repeat and premultiplied tile parity <=1/255.
- X-ray: opaque original fill alpha 1 gives 0.20 interior, original stroke-only area alpha 0.
- Pixel Preview: 40x40 1x CPU reference sampled by integer pixel lookup at 8x,
  compared exhaustively across 320x320 device pixels (no proprietary/external golden).
- Glyph: bundled **Inter**, character O at 18pt; pc-text's existing font/attribution notices
  cover it. Outline/counter assertions and quadratic-to-cubic conversion use pc-text;
  no system font is required by the specified family and no font file is added.
- Engine isolation: 64x64 document, child and outside 8x8 rectangles; nested groups,
  ancestor locks/deletion/stale generations, missing/duplicate/prepared-cache targets.
  Symbol id 700 with translate(20,10)*scale(2), local point (2,2) from document (24,14).
  Depth fixture nests a prepared shape under MAX_GROUP_DEPTH groups and rejects adding
  a sibling group that would exceed the whole-document depth budget, without an edit.
- Kittest host: 200x130 document, group child (20,20,60,60), outside (130,20,30,30),
  double-click (40,40), rectangle drag (90,70)->(120,100), outside (185,110),
  Ctrl/Alt keyboard and Layers clicks, Escape and persona-button click. Pointer isolation
  and real-app harnesses use 1/60-second event steps (kittest's 1/4-second default cannot
  represent consecutive clicks within egui's default 0.3-second double-click window).
- Real-app GPU fixture: 640x480, 2 overlapping 80x80 paths at (20.5,20.5)/(40.5,40.5)
  or 5000 4x5 paths in a 100-column grid, 6x8 spacing, warm 48 pointer frames plus
  release/readback; checker disabled for independent white-background pixel oracle.
  This gate is unrun under owner speed rules; absence/software adapter cannot pass it.

Missing corpus: no licensed external/proprietary artwork was supplied or used. No such
