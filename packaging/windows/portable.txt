Local Image portable mode

While this file sits next to local-image.exe, Local Image keeps its preferences, presets,
crash-recovery autosaves and startup state in the LocalImageData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Local Image with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Local Image) instead.
If LocalImageData can't be written (for example on a read-only drive), Local Image says so and
uses %APPDATA%\Local Image instead.
