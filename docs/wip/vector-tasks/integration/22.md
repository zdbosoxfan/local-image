Public adapter signatures (shared exchange types, no engine/UI dependency):

```rust
import(&[u8], &ImportOptions) -> Result<ImportedScene, ImportError>
import_with(&[u8], &ImportOptions, &PdfOptions, &AtomicBool)
    -> Result<ImportedScene, ImportError>
info(&[u8], &ImportOptions, &AtomicBool) -> Result<PdfInfo, ImportError>
```

`ImportOptions.pages` uses zero-based indices; empty means page 0. UI is one-based.
Multiple pages are arranged left-to-right in requested order. Crop/Media and
rotation suppression supplement the shared options through `PdfOptions`.
Open uses the chosen DPI; Place uses destination DPI to retain physical size.

Engine interface:

```rust
capture(&Session, Vec<u8>) -> Result<Place>
check(&Session, &Place) -> Result<()>
decode(&Session, &Place) -> Result<ImportedScene>
preview(&Session, &Place, &ImportedScene) -> Result<(Document, LayerId)>
publish(&mut Session, &Place, &ImportedScene) -> Result<serde_json::Value>
document(ImportedScene, &str) -> (Document, Vec<VectorWarning>)
```

Capture contains document ID/revision, complete selected target IDs, active anchor
and offset. Check rejects changes, missing targets, locked ancestor destinations,
out-of-range offsets/depth. Preview only clones; publication uses one edit.

likewise call `offer` before raster decoding. The dialog has Open/Preview/Place;

## Deliberate bounded refusals and fallbacks

Encryption returns a specific decrypted-copy-required error, with no passwords
stored. Indirect stream lengths/filters, unsupported codecs (LZW/JPX/JBIG2 etc.),
inline images, calculator functions, external streams, nonuniform dashed hairlines, knockout/nonisolated
transparency groups and cyclic resources return explicit errors before unsafe
unbounded upstream work. This is a conservative bounded importer, not a claim of
complete PDF standards coverage. Flate, raw and bounded JPEG streams are accepted. Sampled-function dimensions
are limited to four; packed meshes/functions and predictor rows are charged for
their expanded allocation before upstream parsing.
Conservative inherited XObject-name resolution may reject unrelated same-name
resources in unusual documents; this is recorded as a limitation.

Native paths, compound holes, clips, isolated groups, blend/opacity, glyph
outlines and isotropic strokes survive. Nonuniform strokes become editable
outlines. Image placement, soft-mask sources, tiling/mesh/function shadings are
baked with warnings; axial/radial paint retains a native gradient mirror with a
warning about editing its simplified geometry. Image resampling is nearest center.
Annotations/private editor data and unsupported font/image decodes are warned.

UI staging is synchronous and bounded; parser cancellation is polled throughout
admission, callbacks and cache sampling. Background decode/progress requires the
coordinator's shared jobs lane, not an unbounded decoder added in this package.
