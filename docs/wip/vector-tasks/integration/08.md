## UI entry points (00 / 01)

01 reserves distinct IDs `Tool::VectorFill` / `vectorFill` and
`Tool::Transparency` / `transparency`. Display names are “Fill” and “Transparency”.
Use the existing color icon aliases as chosen by 01; no brand assets are supplied here.

```rust
use crate::vector_packages::appearance as appearance;
// Appearance panel: ids are the complete existing selected shape layer IDs.
appearance::panel(ui, &mut app.ui.vector_appearance, &mut app.session, &ids)?;
// Tool choice: cancel before changing options.tool.
app.ui.vector_appearance.options.tool = appearance::Tool::Fill; // or Transparency
// Every frame (including focus/tool/persona changes):
app.ui.vector_appearance.synchronize(&app.session, tool_enabled);
// Canvas input, document-space transform from the existing ViewXform:
appearance::input(&mut app.ui.vector_appearance, &mut app.session,
    ctx, canvas_rect, |p| to_doc(p), &ids, tool_enabled,
    6.0 / f64::from(zoom.max(0.01)))?;
// After the normal canvas:
appearance::paint_handles(&app.ui.vector_appearance, &app.session, &ids,
    painter, |p| to_screen(p));
// Escape / modal / tool / persona / document / focus change:
app.ui.vector_appearance.cancel();
```

Use exactly one event consumer; either the module's `input` or route captured down / move /
release through State methods. Release outside canvas still commits the final coordinate.
Sample modifiers each frame. Never send these events to the raster Gradient tool too.
Panel controls already call one `shape.appearance.set` on click/release; continuous changes
prepare detached caches without journaling. Select one item and drag either handle, or drag
inside the canvas to place a new gradient chord. Shift constrains the chord to 45 degrees.
Transparency edits opacity stops while preserving existing color stops. Tool/panel errors
use the app's existing status/error route, not a swallowed Result.

If `vector_appearance.preview` exists, pass that Document to the **normal CPU/GPU canvas
compositor** and include `generation` in the transient plan key. Drop the preview on cancel
and release. Do not overwrite Session, draw an egui polygon as the shape, or upload an extra
flattened image into the full app. The isolated widget host's texture is only its test host.

## Geometry / render hooks (00, 11, 17)

```rust
photocraft_vector::appearance::render_shape(
    &shape, layer.vector.appearance.as_ref(), &doc.patterns, doc.pixel_format(), doc.bounds()
) -> Result<Surface, String>;
```

Use this whenever an appearance shape's path/cache changes (Move/transform/node/pen/native
refresh/pattern edits), retaining the legacy branch for None with no pattern paint. Legacy shape pattern paint also uses this renderer with None and the document pattern table. Those packages currently reject
appearance edits; remove their rejection only after installing this refresh route. A bounds-
limited cache must be prepared before `vector_api::apply_shape_edits`.

When baking a transform, call `scale_with_object(&mut appearance, affine)` **once**;
relative dash values remain relative to the newly scaled width. The area scale
`sqrt(abs(det))` scales width and profile left/right; fixed-width strokes retain width.

11/17 implement `appearance::StrokeProjection::outline(&Path,&StrokeItem)
-> Result<Path,String>`, returning an aligned, dashed, arrow-complete filled document-space
outline. Call `CompiledAppearance::with_projection` or engine `prepare` /
`preview_with_projection`; wire the provider into the registered set command's `prepare`
call when both providers are available. The default explicitly errors for visible profiles
or brushes, without rendering them as a constant-width stroke. Provider tests inject a
licensed synthetic rectangle and test filled coverage; they do not claim 11/17 completion.

SVG adapters use `vector_design::exchange` and their own warning/fallback collector. The
renderer capability utility `check_svg_paint_limits(PaintLimitations)` reports skew,
reflection, anisotropic scale and non-pad spread; native Fill cannot store those. Phase,
rotation and uniform scale are supported. A missing pattern is a render/command error.
Never use this check as an SVG parser or silently turn an unsupported paint into transparent.

## PSD / attribution (23 / 00)

Legacy mirror selects the topmost visible fill/stroke; fill item opacity folds into solid /
gradient alpha. A translucent pattern fill cannot encode item opacity in legacy Fill and
is skipped in favor of the next supported fill. Stroke base opacity is retained. Cache is
authoritative for all rendered pixels; changed shapes clear `shape.psd_raw`.
23 must collect one warning per lost multi-paint/item-blend/item-opacity/arrow/dash-align/
scale-with-object/path-gradient/profile/brush feature, and perform PSD reopen pixel and
warning acceptance. No overlapping pc-io edits are supplied by 08.
