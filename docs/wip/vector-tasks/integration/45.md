## 00: native additive data and access (required before enabling commands/menu)

Types are compiled in `photocraft_doc::vector_design::effects`:
`PathEffect { target: EffectTarget, enabled: bool, effect: EffectKind }`. `EffectTarget`
is Layer(default) or Item { index }; indices refer to the bottom-to-top Appearance items.
Missing target/enabled load as Layer/true; hidden effects remain editable and validated.
Nine typed effects replace upstream's permissive arbitrary JSON parameters.

Append to `pc-doc/src/vector_design.rs::VectorData`:

```rust
#[serde(default, skip_serializing_if = "Vec::is_empty")]
pub effects: Vec<effects::PathEffect>,
// VectorData::is_empty(), append:
&& self.effects.is_empty()
```

The existing native LayerM stores `VectorData` directly and convert clones it in both
directions, so no separate ContentM effect field or format bump is necessary. Review all
VectorData struct literals through the workspace check (use `..Default::default()`). Native
shape and symbol master layers both carry their own stack. Retain FORMAT_VERSION 2.
At engine bootstrap, once (not once per Session), install:

```rust
use crate::vector_packages::path_effects;
path_effects::install_access(path_effects::Access {
    read: |layer| Ok(layer.vector.effects.clone()),
    write: |layer, effects| { layer.vector.effects = effects; Ok(()) },
})?;
// vector_packages::specs():
out.extend(path_effects::specs());
```

Commands: `vector.pathEffects.set` journal=true; `.preview`/`.info` journal=false.
Set/preview take `Request { capture: {document,revision}, edits:[{layer,effects}] }`;
info takes `{layers:[id,...]}` and returns a captured full stack per target. UI writes the
full candidate stack, supporting add/edit/remove/reorder/toggle as one atomic edit.
No command IDs conflict with raster effects. There is no surrogate production storage:
uninstalled access fails explicitly. Test `tF45` PSD blocks exist only in synthetic test
providers and must never be installed in production.

## 08/09: shared geometry before paint and cache/source-edit hooks

Pure API, usable by low-level adapters without engine/UI:

```rust
photocraft_vecfx::path_effects::project(
    &ShapeLayer, Option<&Appearance>, &[PathEffect], Options { dpi, tolerance }
) -> Result<Vec<PaintPath>, Error>
// PaintPath { path: ordinary Path, item: AppearanceItem, source_item: usize }
evaluate(&Path, &[PathEffect], Options) -> Result<Vec<Path>, Error>
```

Layer effects affect every paint path. Item effects affect only that indexed fill/stroke
centerline before paint, including stroke-only distortion. Copies are separate paint
operations (source plus N when N>0, transformed source only when N=0), with complete
bottom-to-top appearance order for each layer duplicate. Do not concatenate them into a
single filled Path: overlapping translucent duplicates must composite independently.
Geometry controls remain document-space pixels, angles in degrees (positive CCW in y-down),
scale in percent, Roughen detail per physical inch using document DPI. `extra` is total
extra width/height. Free Distort corners are TL/TR/BR/BL normalized to analytic bounds.
A flat axis uses a one-pixel frame. Round Corners reuses the 06 evaluator source; Offset
calls V1 directly. Original explicit closedness, FillRule and ordered PSD PathOps survive
geometry mapping; Convert to Shape intentionally creates its new primitive outline.

Engine provider order:

```rust
path_effects::project(&Layer, &[PathEffect], doc.resolution_dpi)
    -> Result<Vec<PaintPath>>
// Internally: 02 generator -> 06 live corners -> 45 effects -> 08 paint.
path_effects::refresh(&Document, &mut Layer, Access) -> Result<()>
path_effects::project_document(&Document, Access, &mut ProjectionCache) -> Result<Document>
```

`refresh` prepares a bounds-limited merged cache while retaining source path/live/corner
metadata and effect parameters. Call it on source path edits (03/04/05/33/34/V1), parametric
shape/corner updates (02/06), appearance edits (08), native reload and style/master refresh.
The **detached projected document** is the authoritative compositor/display/export input:
its affected source layers become ordinary paint-ordered groups under the original layer
ID/transparency/masks/clip/effects. Clear source effects on that transient group via Access;
do not overwrite Session.doc or reuse source revision keys for previews.

Do not let shape_split recompute an unprojected source stroke or outline around its base path.
Use the detached ordinary children, or an 08 merged enhanced-shape path that explicitly consumes
PaintPaths. `render::Compiled::new(scene,patterns,canvas,StrokeProjection)` rasterizes all
ordinary paths through pc-vector and uses pc-color compositing; existing 11/17 provider is
`expand::Projection`. No renderer replacement or dependency cycle.

For scaled view, evaluate 45 first at document scale; then use
`path_effects::scaled_paint(doc, ordinary_child, scale, clip) -> photocraft_engine::Result<Surface>`
through a 09 callback wrapper for the affected child shapes:

```rust
fn project_effect_paint(doc: &Document, layer: &Layer, scale: f64, clip: Rect)
    -> Result<Surface, crate::view::cpu::ViewError> {
    path_effects::scaled_paint(doc, layer, scale, clip)
        .map_err(|e| crate::view::cpu::ViewError(e.to_string()))
}
```

09's current `scaled_view` source is compiled through its UI `view::cpu` bridge; public
pc-compose registration is still pending in 00. 45's GPU fixture requires injection of 09's actual shared scaled provider after integration,
so it does not register or compile a competing renderer. The coordinator's integration
GPU bootstrap must call the public test-only `path_effects::gpu::scaled::install` with
`fn(&Document, f64) -> engine::Result<Document>` implemented via the shared 09 cache and
this paint wrapper. Missing injection is an explicit failed gate. It scales paths, stroke widths,
profiles and pattern phase using the current renderer; it never re-samples Roughen by
viewport zoom. Use 09's ordinary providers for unrelated text/raster/symbol layers. Key the
parent group on source/effect metadata and the view scale; 09 rewalks child state. A changed
source/effect invalidates geometry; an unrelated document/layer edit hits 45's geometry
cache (8 entries, source layer ID/path/VectorData/legacy paint/effects/DPI, no document revision).
Cached projections retain stable transient child IDs on hits, so 09 can reuse child tiles.
Paint keys also include patterns and 09's exact affine/CMS/scale dependencies.

Budgets: <=64 targets/effects, <=4096 paint paths, aggregate <=65536 knots, finite coordinates
within ±1e6. One prepared target set preflights merged plus expanded child caches against
512 MiB before pixel allocation. Nonlinear map fitting has depth/work guards and numerical
sample checks (not a proof of interval error). Incompatible clip/live/on-path metadata
currently fails through 36's base provider; hook the shared 35/20 projection before enabling
those combinations. No stale source cache or empty-success fallback is substituted.

Appearance item edits must call `effects::remap_items(&mut stack, old_to_new)` in the same
edit. Deleted paints drop their attached effects; reorder preserves the original binding;
copying a paint copies/remaps its attached effects according to 08's item policy. Do not
silently retarget by keeping stale indices.

## 00/08: production UI menu, Appearance section, Preview and modal routing

```rust

path_effects::app_hooks::display(app, ctx, idx) -> Option<(Arc<Document>, u64)>
```

Menu labels: Effect > Distort & Transform (Roughen, Zig Zag, Pucker & Bloat, Twist, Transform),
Stylize (Round Corners, Offset Path), Other Path Effects (Free Distort, Convert to Shape).
01/46: these are commands/dialogs, no new canvas tool or conflicting shortcut; reuse an
existing effect icon. Merge `i18n/45.tsv` through 00's catalog tooling.

State provides `menu`, `panel`, `dialog` with translator, Access and Dispatch inputs.
Production Dispatch is `path_effects::command`, which executes the registered journaled
command. Synthetic kittests explicitly inject the lower-level commit to exercise owned UI
while native registration is absent; this is not full-app journal acceptance.
Dialog captures document/revision/target IDs once. Preview stays detached; changing parameters
updates preview, Preview unchecked clears it, OK revalidates/renders and publishes once.
Escape/Cancel/window close/persona/tool/module/document/revision switch clear transient state.
Host must suppress normal canvas gestures/shortcuts while `owns_modal` is true and must
cancel for any other modal owner (camera raw, discard, gallery, text/transform/pen/direct
selection/live stroke), matching 36's modal routing. Panel supports actual drag reorder,
up/down buttons, visibility, edit and delete. Select targets with compatible stack positions;
add rejects inconsistent stack lengths across selection. Error does not partially publish.

## 36: Expand Appearance

Before normal shape expansion, if a layer has 45 effects:

```rust
let access = path_effects::access()?;
let effects = (access.read)(layer)?;
let scene = path_effects::project(layer, &effects, doc.resolution_dpi)?;
let mut expanded = path_effects::projected_layer(layer, &scene, doc)?;
(access.write)(&mut expanded, Vec::new())?;
// Continue the existing detached recursive shape_expansion with appearance=true
// on the ordinary children, outline strokes via 08/11/17, and publish under the
// existing object.expand one-Session::edit transaction, preserving source layer ID.
```

Recheck cache budget across the whole Expand request. Hidden effects are bypassed and cleared
when baking; the original editable source is restored by Undo. Child shape paths are ordinary
and effects are absent; the current provider retains an ordinary single-item Appearance so
08 coordinates/pattern/advanced stroke semantics stay authoritative until 36 expands them.
Do not independently re-evaluate source base geometry in exporters.
