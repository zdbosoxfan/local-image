## Evaluator and stroke-output boundary for 28 / 11

Public pc-trace API:

```rust
centerline::trace(Image, &Params) -> Result<CenterlineTrace, pc_trace::Error>
centerline::trace_with_cancel(Image, &Params, impl Fn() -> bool)
    -> Result<CenterlineTrace, pc_trace::Error>
// CenterlineTrace { width, height, strokes: Vec<StrokePath>, nodes }
// StrokePath { path: Path, stroke: ShapeStroke, profile: Option<WidthProfile> }
```

Every result is an individual open graph run with its own width profile. Rings
repeat their start point at the end, with `closed=false`, preventing fill routing.
An isolated point is two coincident knots with round cap (pc-vector's existing
point-stroke support). The base stroke is black, round cap/join, centered;
profile points are normalized positions with absolute left/right half widths.
Constant profiles are omitted. The exact grid EDT includes exterior background;
width = `2*sqrt(squared_distance)-1`, with analytic half-pixel normal ridge refinement from the
EDT's nearest background sites. This resolves even-width plateaus and diagonal
lattice bias, retaining shared endpoints. This is a pixel-site distance convention, not a
claim of exact continuous boundary reconstruction from antialiasing.

No upstream chamfer saturation or area-over-length width estimate. No automatic
spur pruning that deletes legitimate short arms. T/cross meeting pixels survive
staircase cleanup. Fitting calls the existing T1 kurbo refiner in bounded chunks;
shared endpoints are restored exactly after fitting. Cancellation polls at most every
1024 elementary visits, per analytic ridge sample and between fits (256 edges maximum per call). Global
work bound 128 million visits, 8192 strokes, 1,048,576 total output knots and total width markers, 4096
width markers per run; exceeded complexity returns BoundaryBudget, no partial
success. Input pixel and buffer validation precede allocations.

`photocraft_engine::vector_packages::trace_centerline` supplies:

```rust
capture(&Session, source: LayerId, origin: [f64;2], scale: f64) -> Result<Capture>
check(&Session, &Capture) -> Result<()>
prepare(&Session, &Capture, &CenterlineTrace, &dyn StrokeProjection,
        impl Fn() -> bool) -> Result<Prepared>
preview(&Session, &Prepared) -> Result<Document>
publish(&mut Session, Prepared) -> Result<LayerId>
```

Capture BEFORE the existing cancellable background job. Capture records
source, complete selection/active IDs, doc ID/revision, selection-crop origin
and preview scale. A new revision, changed selection/active, missing/locked
source/target/ancestor, invalid scale/origin or excess depth is an error.

After the worker finishes, recheck Capture; construct CenterlineTrace from the
public Trace's stroke fields; prepare all descriptors and validate all output
before any caches; compile bounds-clipped paints; charge aggregate tile storage
against 512 MiB before rendering. Origin translates path positions; 1/scale
scales both positions, stroke width and absolute profile widths. Prepared
contains shape children with no fill, a legacy stroke mirror and an authoritative
Appearance StrokeItem/profile. Preview clones; publish inserts exactly the same
prepared group using one Session::edit. 28's journaled command remains the sole
journal owner. Never call both this publish and T1's old s.edit closure.

For varying widths pass package 11's real StrokeProjection. NoProjection yields
an explicit package-11-required error. Uniform strokes already render through
the current appearance renderer. Do not drop the profile to make tests pass.
Renderer/export consumers must retain that same projection after later edits.

The bridge supplies no command registrations: no duplicate layer.vectorize IDs.
In T1 `vectorize_cmds::params`, after obtaining the default parameter object and
before checking overrides, 28 must admit the optional mode key even when serde

```rust

```

Retain rejection of all other unknown keys. Without this admission, an explicit
`mode: "centerline"` override is rejected by T1's default-object membership test.
Do not merely remove the unknown-key guard. Likewise, the apply path must branch
on result strokes and use prepare/publish BEFORE entering the old filled-layer

28 wraps this boundary in existing jobs/menu/dialog/Make Work Path/Expand paths,
