## Compiled slots (00)

In `crates/pc-engine/src/vector_packages.rs`:

```rust
pub mod selection;
// in specs():
out.extend(selection::specs());
```

In `crates/pc-ui-egui/src/lib.rs`:

```rust
#[path = "vector_packages/selection.rs"]
pub mod vector_selection;
```

These register `vector.select` and `vector.select.query`, both `journal=false`.
The first evaluates/preflights the whole set and publishes existing `DocState` selection
fields, without `Session::edit`, revision increments, journal entries, history, damage
or document/cache changes. The second is entirely detached. Both return a `Preview`.
Do not route them through existing `select_layer`/`layer.select`: those increment revision.

```json
{"document":123,"revision":42,"scope":{"editAllLayers":true,"selectHidden":false,"active":456,"isolation":null},"mode":"replace","query":{"type":"same","criterion":"fillColor","reference":456,"compare":"equal","value":null,"item":null}}
```

`mode`: replace/add/subtract. `compare`: less/lessEqual/equal/greaterEqual/greater.
`Query` variants:

- same: criterion fillColor/strokeColor/fillAndStroke/strokeWeight/opacity/blendMode/
  appearance/appearanceAttribute/graphicStyle/shapeType/width/height/rotation/name,
  reference layer, optional compare/value/item.
- object: allOnSameLayers/openPaths/strayPoints/clippingMasks/textObjects/groups/
  symbolInstances/unfilled/stroked/unstroked.
- wand: reference layer plus `Wand` settings; all enabled attributes are conjunctive.
- lasso: document-space points, nodes bool; object mode touches actual paths, node mode
  encloses anchors on all currently selected shape curves.
- group: leaf layer, previous selected ancestor (optional).
- all/deselect/inverse/next {above}/artboard {board}/reselect {ids}.

Numeric values are finite and bounded. Colour tolerance is **100× Oklab ΔE**, continuous
sRGB, range 0..200. Weight is document pixels (convert pt/mm in the context bar); opacity
is percentage points, 0..100. Equal dimensions/weight use 1e-9 tolerance. Fill/stroke use
topmost visible appearance items; gradients/patterns match exactly. Appearance compares
all ordered items, layer opacity/blend and layer effects. Appearance Attribute tests an
exact fill/stroke item against any item in each candidate stack. Shape Type means live
shape kind, not parameter equality or polygon recognition. Rotation uses live-shape angle
or a supplied transform reader, and rejects an undefined reference rotation.

Edit All Layers false descends all nested objects in the active artboard, per Affinity's
official help. Without artboards, its documented fallback is immediate siblings of the
active object; at root it excludes group contents. True descends eligible groups across
artboards. All queries apply inherited all/pixel locks, inherited visibility (unless Select
Hidden), and the isolation container. Group Selection may descend sibling scope for its
leaf hit, stays inside the active artboard/container, and stops before the isolation root
or active artboard boundary. Position-only locks allow selection.
“All on Same Layers” uses selected objects' immediate containing groups (root is one
container in Local Image's object-as-layer model). Artboard query uses geometric overlap
with the named board. Next Above/Below uses eligible leaves in document paint order, no
wrap, retaining selection at the end. Reselect validates saved IDs, so deletion produces
a missing-target error without a partial selection. Empty matches deselect.

## Authoritative scope and reselect memory (00 / 37)

Add `pub vector_selection: selection::Memory` to `DocState`, initialized with Default.
Keep Edit All Layers/Select Hidden in the existing view/preferences store chosen by 00,
and use 37's real isolation query. Install once:

```rust
selection::install_hooks(selection::Hooks {
    scope: |s| {
        let st = s.active().ok_or(EngineError::NoDocument)?;
        Ok(selection::Scope {
            active: st.active_layer,
            edit_all_layers: /* existing view preference */,
            select_hidden: /* 32 Settings.select_hidden, shared menu preference */,
            isolation: /* 37's authoritative container query */,
        })
    },
    previous: |s| s.active().map(|st| st.vector_selection.previous.clone()).unwrap_or_default(),
    remember: |s, ids| { if let Some(st) = s.active_mut() { st.vector_selection.previous = ids; } },
});
```

The hooks override untrusted caller scope, share menu/MCP/canvas memory, and validate
scope again before publication. There is no global document/session history map in the
engine. The widget's `State.previous` is only the unintegrated host fallback. After hooking,
all Reselect requests take `Hooks.previous`. `resolve_scope(session, &fallback)` is used
by canvas capture and previews as well as command publication, so provider scope changes
cancel a gesture. Register a callback for legacy Layers-panel
selection changes as well if Reselect should restore those selections. Do not replace the
existing selected-layer set. `Preview.base` catches concurrent selection changes even
though selection itself does not change document revision.

## Readers (08, 15, 38 through 00)

`selection::install_readers(Readers { appearance, graphic_style, rotation,
symbol_instance })` is a once-only, read-only provider boundary:

```rust
appearance: Option<fn(&Layer) -> Result<Appearance>>,
graphic_style: Option<fn(&Layer) -> Result<Option<String>>>,
rotation: Option<fn(&Layer) -> Result<Option<f64>>>,
symbol_instance: Option<fn(&Layer) -> bool>,
```

08's public reader should supply the whole authoritative stack. Before that lands,
selection reads `Layer.vector.appearance` data if present, otherwise normalizes legacy
fill/stroke and text colour; an explicit empty stack remains unpainted. No appearance
renderer is copied or invoked by selection. 38 supplies its stable graphic-style link
as a string; an absent provider or missing reference link is an explicit error. This
branch has no `LayerContent::Symbol` variant yet: 15/00 must supply the symbol predicate;
Select Symbol Instances returns an explicit dependency error until then. The predicate also adds instances to leaf
paintability; the merged model's normal surface/cache accessor supplies bounds. Rotation
reader supplies degrees for objects whose transform is not represented by DesignShape.
V1's actual contains/nearest/bounds/flatten exports are already used directly. The 07
snapping query is not repurposed as an invented object hit provider.

## Required geometry-bar performance bridge (00 / 01)

The release app with only registration/canvas/frame hooks fails the 16 ms gate:
single-event pointer-frame median 81.155 ms, p95 82.025 ms, p99 82.228 ms on RTX 5090.
Selection route costs only 0.05–0.06 ms; GPU/readback is about 2.2 ms. All 500 overlay
edges are visible and canvas interior diff is 0/255. The one-selected-object baseline
is 3.45–4.35 ms. This is a **failed gate**, not a performance pass.

The debugger sample in `target/selection32/release-ui-stack.log` identifies
`GeometryRequest::validate` → `Document::effective_locks` → `Document::path_of` in
the existing persona geometry bar. Five buttons validate all 500 targets every frame;
each layer lookup rebuilds a complete layer walk. The following exact replacement for
the `for id in &self.target.layers` loop in
`crates/pc-ui-egui/src/vector_packages/persona.rs::GeometryRequest::validate` retains
the existing shape, inherited-all-lock, missing-ID and current-target checks. It keeps
all controls enabled and still validates again on click. No geometry control is hidden:

```rust
let mut missing: std::collections::HashSet<_> = self.target.layers.iter().copied().collect();
for (path, _, layer) in st.doc.walk() {
    if missing.remove(&layer.id)
        && (st.doc.locks_at(&path).all || !matches!(layer.content, LayerContent::Shape(_)))
    {
        return Err(tl!("Select at least two editable shape layers").into());
    }
}
if !missing.is_empty() {
    return Err(tl!("Select at least two editable shape layers").into());
}
```

The first replacement alone reduces p95 to 32.289 ms, still failing. A second debugger
sample (`target/selection32/release-ui-stack-with-bridge.log`) identifies the remaining
per-ID lookup loop in `GestureTarget::is_current`. Remove just its final conjunct:

```rust
&& self.layers.iter().all(|id| st.doc.layer(*id).is_some())
```

The preceding `st.selected_layers() == self.layers` already proves existence: the
established session reader constructs its result from the current document walk and
prunes IDs absent from the document. Keep the document/revision/active/selection equality
guards. `GeometryRequest::validate` still checks every selected shape and inherited lock,
and rejects missing IDs with the replacement above. This removes redundant lookups,
without weakening staleness or eligibility validation.

Both changes are supplied as integration requests; the production persona file is unchanged.
The disposable copy applies them to measure the complete app with the proposed bridges.
The owned selection route reports its cost through the existing `Perf.spans` entry
`vector-selection`. With both fragments, the final focused release run passes all ten
UI tests, including the strict benchmark: median 4.256 ms, p95 4.420 ms, p99 4.431 ms,
500/500 overlay edges detected, canvas interior max diff 0/255. Full timing/results
are recorded in the package report.

uses the ordinary Path Selection tool, rather than requiring an active selection-family

## Shared shape-properties regression found during app acceptance

The first full-app Node fixture was a rectangle with anchors `(5,5)`, `(11,5)`,
`(11,9)`, `(5,9)`. Lasso selected the first two; 03 Delete correctly left the
bottom two. The existing shape width/height properties then issued four additional
`shape.edit` commands with `coalesce=shape-2-wh` and transform
`[1,0,0,1000000,0,-8999991]`, because the resulting path has zero height.
This breaks one-step Undo in that case. Reproduction/journal evidence:
`target/selection32/focused-delete-diagnosis.log`. The shape-properties UI and its
shared command bridge are outside 32's ownership; 00/02 must prevent edits caused
merely by displaying a zero-width/height path and repeat this rectangle case.

The delivered full-app Node gate uses the four-node diamond `(5,7)`, `(8,5)`,
`(11,7)`, `(8,9)` and selects the first two. It asserts the exact other two nodes,
one Delete journal entry, and complete Undo. The small UI host independently retains
the rectangular two-of-four oracle. Neither gate disables the properties UI.
