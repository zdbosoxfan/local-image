## V0 renderer handoff to 08

The previous builder's #1321 port is already merged. Package 00 verified the
upstream Paint/gradient block and retained its independent analytic, fill-layer
parity and GPU parity tests. No renderer algorithm edits are needed in this lane.
Package 08 may take renderer ownership after this package's acceptance; retain:

```rust
Paint::from_fill(&Fill, layer_frame: (f64,f64,f64,f64), canvas_frame: (f64,f64,f64,f64)) -> Paint
CompiledShape::new(&ShapeLayer, tolerance: f64, canvas: Rect) -> CompiledShape
CompiledShape::render(&self, PixelFormat, clip: Rect) -> Surface
render_shape(&ShapeLayer, PixelFormat, clip: Rect) -> Surface
```

Pass the full canvas to `CompiledShape::new`, then the bounded region to
`CompiledShape::render`. The `render_shape` convenience function uses its clip
as the canvas frame, so its callers supply document bounds. Canvas frame and
clipped render bounds are separate. Sorting, midpoints, opacity,
offset, dither, pixel endpoint snapping and all five PSD gradient layouts stay
honored. Preserve the #1495 depth-aware split caches and Move translation cache
restrictions for canvas-aligned/dithered paint. #865/#747 require no re-port.
