## Compiled interfaces

`photocraft_engine::vector_packages::transform_tools`:

- `Capture::begin(&Session, &[LayerId]) -> Result<Capture>` captures document/revision/roots.
  `Capture::check(&Session)` rejects stale gestures and revalidates targets, descendants,
  inherited position/pixel/all locks, duplicates and overlapping root/child selections.
- `Commit { capture, operation, options, copy, conversion }` is serializable. `Options`
  defaults `objects=true, patterns=true, scale_corners=true, scale_strokes_effects=false`.
- `Operation::Affine {matrix:[f64;6]}` uses kurbo coefficient order; helpers
  `rotate(origin,degrees)`, `reflect(origin,axis_degrees)`, `scale(origin,sx,sy)`,
  `shear(origin,degrees,vertical)`, `move_by(distance,degrees)`. UI/numeric angles are
  counter-clockwise on a document with Y down. Positive horizontal movement is right;
  positive vertical movement is down. `about` consumes actual kurbo Affine via V1's reexport.
- `Operation::Distort {source:[x,y,width,height],quad:[[x,y];4],perspective,tolerance}`:
  quad order TL/TR/BR/BL. Bilinear for Free Distort, homography for Perspective.
  Tolerance 0.000001..0.25 destination px. No handle-only cubic warp.
- `Operation::Each(Each {scale,movement,rotation,reflect,reference,random,seed})`:
  per-selected-root geometric bounds; reference indices 0..8, row-major top-left to bottom-right.
  Groups transform as objects; descendants share their group's matrix. Seeded xorshift64*
  follows the pinned VC recipe. Identical seed/order gives identical geometry. Reflect X
  negates Y and Reflect Y negates X. Scale is a factor, not percentage, in engine payloads.
- `Operation::Reshape {nodes:Vec<Node {layer,subpath,knot}>,delta,radius}`: selected nodes
  move exactly; same-subpath neighbours follow max `(1-(distance/radius)^2)^2`, clipped to
  zero beyond radius. All node indices validate before publication; anchors and handles
  move together. Live geometry becomes ordinary paths.
- `prepare(&Session,&Commit) -> Result<Prepared {document,targets,..}>` is detached.
  Prepares changed geometry for all roots, checks aggregate cache budgets, then renders
  bounds-limited caches using actual appearance/corner/width/brush providers. Up to 1024
  objects and 512 MiB aggregate caches. Type/symbol affine raster providers receive a
  conservative tile/scratch budget for the complete set before any provider rasterizes. Unselected layers remain shared COW caches.
- `commit(&mut Session,&Commit) -> Result<Vec<LayerId>>` issues one engine command and one
  Session::edit. Copy retains originals, gives every descendant a fresh ID, preserves parent
  placement and selects copied roots. Errors do not publish/history/journal. Undo restores.
- `vector.transform.apply {capture,operation,options?,copy?,conversion?}` journal=true.
- `vector.transform.preview` uses same payload; journal=false; verifies detached preparation.
- `vector.transform.again {layers?:[id]}` journal=true; use selected roots when omitted.
  `again_request(&Session,&[LayerId])->Result<Commit>` resolves the last successful vector
  apply payload for the active document, preserves operation/options/copy, captures current
  revision/targets. Reshape node IDs remap by corresponding root/relative descendant path
  after Copy, with structure validation. This is the 00 bridge; do not change Pixel's edit.transform state.
  UI issues the resolved apply through `commit`, keeping automation replay explicit.

`photocraft_vector::projective::{Map,Mapping,map_path}` is independent of engine/UI/V1.
`Map::perspective(source,[Point;4])`, `Map::bilinear(source,[Point;4])`, `Map::point`;
`map_path(&Path,Map,tolerance) -> Result<Mapping {path,error_bound,intervals},Error>`.
Intervals identify (source subpath, segment, t0, t1). Rational/polynomial Bernstein
certificates cover entire intervals; adaptive endpoint Hermite refits use at most 24 splits,
131072 output nodes, bounded finite coordinates. Folded quads, horizons, singular transforms
and exhausted budgets are errors. Straight source rectangle sides remain straight; corners
are exact. Fill rules, ordered component operations, closure and source smooth flags survive.
Lower-level exporters use this pure API and vector_design::exchange, never engine/UI.

## Conversion/envelope and remaining provider integration

Free Distort/Perspective of text/symbols prompts `Convert to Curves` or `Non-destructive
Envelope` on release. Curves detach symbols through 15, use pc-text outlines for ordinary
single-colour warped text, then transform and commit atomically. Unwarped styled and path
text reuse 12's painted outlines and the established native contour adapter, preserving colour,
faux bold and decorations. Styled warped text requires a painted warp provider and fails
before editing. `EnvelopeRequest {transform:Commit}` retains document/revision/targets/map/options.
20 implements `EnvelopeRouter::{preview,commit}`; call State::preview_envelope/commit_envelope
with that provider. Package 20 is an empty slot in this branch. No fake envelope is committed.

Other existing schema/provider limits are explicit errors: general affine/reflected pattern
paint frames, non-affine pattern warp, shape/group linked pixel masks, live Blend/Repeat/Envelope roots,
combined brush/profile/arrows unsupported by their owning projectors. Ordinary pattern
similarity + phase and Patterns-only transforms work. Patterns disabled retains canvas
phase for affine and nonlinear geometry. Affine type/symbol masks use the existing
layout transform provider; shape/group raster mask routing remains a bridge for 00. Live cogs and spirals reflected into an
unrepresentable handedness bake to curves, following persona §5. Legacy live Lines stay live.
