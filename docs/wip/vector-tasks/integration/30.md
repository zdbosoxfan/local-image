## Audit / exact APIs

- `photocraft_text::frame_compose::compose(&mut TextEngine, &TextLayer, dpi: f32,
  Options) -> Result<Composition, Error>`; Composition exposes native TextLayout, overflow
  byte and Route. Defaults are off, all coordinates are text-space pixels.
- `render_bounded(&Composition, &TextLayer, PixelFormat, Rect) -> Result<Rendered, Error>`
  uses the existing rasterizer, guards 16,777,216 pixels before allocation and retains only
  document bounds. UI preparation also limits aggregate edited-cache area to that budget.
- `photocraft_ui_egui::frame_compose::{Edit, Draft, State, Metadata, NativeOnly}`.
  `Draft { document:u64, revision:u64, edits:Vec<Edit> }`.
  `Edit { layer:LayerId, frame:[f32;4], align:Option<TextAlign>, options:Options }`.
  `preview(&Session,&Draft) -> Result<Document>` and
  `commit(&mut Session,&Draft,&impl Metadata) -> Result<()>`.
  Commit clones/preflights the entire target set, prepares all native caches and TySh,
  stores all metadata in the detached document, rechecks freshness and makes one edit.
  Failed store publishes nothing. Direct Session::edit creates one undo step but does not
  add a command-journal entry; an optional command adapter must call the same preparation
  implementation from the engine side and let Session::execute own command journaling.
- `State::begin(&Session, &[LayerId], &impl Metadata)`, `update(&Session)`,
  `apply(&mut Session,&impl Metadata)`, `cancel()`, `synchronize(&Session,enabled:bool)`.
- `panel(&mut egui::Ui,&mut State,&mut Session,&impl Metadata) -> Result<()>`.
- `input(&mut State,&mut Session,&egui::Context,canvas:egui::Rect,
  to_text:impl Fn(Pos2)->(f32,f32),enabled:bool,&impl Metadata) -> Result<()>`.
- `overlay(&mut Ui,&State,&Session,to_screen:impl Fn(f32,f32)->Pos2)`.

The input transform **must include the layer transform** as well as view zoom/pan. Only
route these controls/width handles when the active target is Box text without on_path.
Call synchronize with `enabled=false` on tool/persona changes; call cancel on focus loss.
Escape cancels; handle release/Enter/apply commits. Route this hook before the legacy
Box-width handler; snapshot `dragging || draft.is_some()` before input and inspect it after
input, consuming the gesture when either is true (including its release/cancel frame). This
prevents two handlers editing the same captured pointer event. Native point/path inputs
retain their existing routing. A drag captures IDs/document/revision once. Pointer updates are detached, non-journaled and can be dropped immediately.

```rust
pub struct NativeMetadata;
impl Metadata for NativeMetadata {
fn load(&self, doc: &Document, id: LayerId) -> Result<Options> {
    let m = doc.layer(id).ok_or(EngineError::NoLayer(id))?
        .vector.frame_compose.unwrap_or_default();
    let o = Options { enabled:m.enabled, balanced:m.balanced,
        optical_margins:m.optical_margins, grid_spacing:m.grid_spacing,
        grid_origin:m.grid_origin };
    o.validate().map_err(|e| EngineError::Other(e.to_string()))?;
    Ok(o)
}
fn store(&self, doc: &mut Document, id: LayerId, o: Options) -> Result<()> {
    o.validate().map_err(|e| EngineError::Other(e.to_string()))?;
    doc.layer_mut(id).ok_or(EngineError::NoLayer(id))?.vector.frame_compose =
        (o != Options::default()).then_some(FrameCompose {
            enabled:o.enabled, balanced:o.balanced, optical_margins:o.optical_margins,
            grid_spacing:o.grid_spacing, grid_origin:o.grid_origin,
        });
    Ok(())
}
}
```

Do not substitute NativeOnly for enabled composer persistence: it explicitly rejects any
nondefault option commit to prevent cached-only success. NativeOnly supports real existing
frame width/paragraph changes and their undo, as exercised in the package tests.

```rust
pub fn refresh_frame(
    doc: &Document, t: &mut TextLayer, options: photocraft_text::frame_compose::Options,
) -> Result<photocraft_text::TextLayout> {
    let mut engine = photocraft_text::shared().lock()
        .map_err(|_| EngineError::Other("text engine unavailable".into()))?;
    let composed = photocraft_text::frame_compose::compose(
        &mut engine, t, doc.resolution_dpi, options,
    ).map_err(|e| EngineError::Other(e.to_string()))?;
    let rendered = photocraft_text::frame_compose::render_bounded(
        &composed, t, doc.pixel_format(), doc.bounds(),
    ).map_err(|e| EngineError::Other(e.to_string()))?;
    t.cache = Some(rendered.surface);
    t.psd_raw = Some(std::sync::Arc::new(photocraft_text::psd::build_tysh(
        t, doc.resolution_dpi, composed.layout.bounds(),
    )));
    Ok(composed.layout)
}
```
