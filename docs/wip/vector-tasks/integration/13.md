```rust

#![deny(clippy::unwrap_used, clippy::expect_used, clippy::panic,
        clippy::unimplemented, clippy::todo, clippy::unreachable)]
pub mod import;
pub use import::{import, import_with, ImportError};
```

`import(bytes: &[u8], options: &ImportOptions) -> Result<ImportedScene, ImportError>`
is the common lower-level file adapter; it has no engine/UI dependency.
`import_with(bytes, options, Option<&mut pc_text::TextEngine>, &AtomicBool)`
allows an explicitly populated font database and cancellation. It never initiates
font scanning or image/file/network fetching. Open/Place/Paste route bytes through
this adapter. File reads must use the existing bounded reader; SVGZ decompression
is bounded by both bytes and decompressed_bytes. Place/Paste use destination DPI.

Engine specs are already registered by `vector_packages::svg_import::specs()`:

- `file.svg.import {svg,dpi?:72,name?:"SVG"}` creates a new native document.
- `file.svg.place` and `file.svg.paste` take serialized `svg_import::Place`:
  `{document,revision,above:id|null,svg,offset?:[i32,i32]}`. Guards are mandatory.
  Both return `{layer,warnings}` and publish one Session edit/journal entry.
- `capture(&Session, String) -> Result<Place>` captures current ID/revision/anchor.
- `decode(&Session, &Place) -> Result<ImportedScene>` prepares source caches once.
- `preview(&Session, &Place, &ImportedScene) -> Result<(Document, LayerId)>`
  validates freshness/anchor/parent locks/depth and returns a detached clone.

Ordinary native cubic paths, fills/strokes, groups, vector clips, raster masks,
text runs and raster images remain editable. Mask source vectors, image placement,
SVG gradient affine/spread/focal data, text path/per-character/percentage positioning and
stroke-before-fill have explicit warning/fallback semantics. Package 08 needs a
projection/paint-data extension to retain arbitrary SVG paint geometry after edits;
the current read-only Fill/Appearance foundation has no field for it. This job
does not expand those shared types independently. Package 12 text-path mapping is
pending its actual provider API; the compiled slot on this base is empty.

## App registration (00)

Register `pub mod svg_import;` in the UI vector_packages aggregate and expose the
aggregate from lib.rs. Add transient fields to **PhotocraftApp**, not serde UiState:

```rust
pub svg_import: crate::vector_packages::svg_import::State,
pub svg_import_dialog: bool,
// new(): Default::default(), false
```

Existing Open/Place/clipboard routes populate `svg_import.source` and display
`controls(ui, &mut app.svg_import, &mut app.session)` in the existing dialog host.
Open passes the bounded file's UTF-8 source (or calls the byte adapter for SVGZ).
Place/Paste use State::place, and Preview uses State::stage. Do not route SVG through
the raster file decoder. Keep the current user-selected file path/name for Open.

Canvas routing, before legacy input, in primary active `canvas_view` after ViewXform:

```rust
let svg_active = primary && app.svg_import.pending();
if svg_active {
    crate::vector_packages::svg_import::input(
        &mut app.svg_import, &mut app.session, &ctx, rect,
        |p| { let d = xf.to_doc(p); egui::pos2(d[0] as f32, d[1] as f32) },
        true,
    )?; // normal app status/error route, cancelling on error
}
```

While `svg_active`, suppress legacy tool and Move input for this frame, including
the release frame. This avoids a second command when pending clears on release.
The scratch registration used `!svg_active` on Move's canvas_input and treated
`svg_active` as an inert-tool dialog in the later legacy input section. Navigation
may still pan/zoom. Cancel on tool/persona/modal changes and focus/pointer loss,
call synchronize each frame/document switch. Captured releases outside the canvas
remain honored. Pointer placement rounds to integer document pixels, so cached SVG
paints retain exact phase while translating. Fractional placement is not claimed.
The later `else if primary` branch immediately after the Hand-pan branch must
be `else if primary && !svg_active`. Merely adding SVG to `under_dialog` is
insufficient: ordinary modal egui layers make that response inert, while the
detached SVG preview has no modal layer. This prevents Move's auto-select from
publishing a `layer.select` revision during the captured gesture.

At the beginning of `canvas::display_doc`, before normal preview selection:

```rust
app.svg_import.synchronize_context(
    &app.session, app.ui.tool, app.current_module,
    app.current_module == crate::Module::Compositing && app.ui.dialogs.is_empty()
        && app.ui.transform.is_none() && app.ui.text_edit.is_none(),
);
if app.session.active_index() == Some(idx)
    && let Some(doc) = &app.svg_import.preview
{
    return (doc.clone(), app.svg_import.generation | (1 << 60));
}
```

Use the same detached document/generation for the normal GPU/CPU compositor and
Navigator. Nothing is journaled or persisted during motion. On release/cancel the
ordinary committed document becomes active. The warning button selects its named
affected layer; warnings about omitted objects/definitions have disabled buttons.
`warning_controls` can also live in the app's existing notification/details host.
`State::preview` is an `Option<Arc<Document>>`; clone that Arc rather than
allocating a new one each draw. Navigator's asynchronous snapshot check depends
on stable Arc identity between pointer updates.
The host also calls `cancel()` when switching away from Compositing (which may
stop calling this app entirely) and on the package 01 persona transition. The
context check cancels changes between the established tool/module values; no
persona field is invented on this older base.

## Test registration

Engine-owned tests are inline registered by the slot. UI module tests are inline
registered when the module is exposed. Append to the existing GPU test aggregate:

```rust
#[path = "../../../pc-engine/src/vector_packages/svg_import/app_acceptance.rs"]
mod svg_import_app_acceptance;
```

This strict offscreen **PhotocraftApp** gate uses Vulkan/discrete/RTX 5090 and
Rgba32Float, real canvas press/motion/release, presented preview/release pixel
checks <=1/255, editability, warning click, cancellation and Undo at 1x/HiDPI.
Visible opaque gradient ink is also compared directly with the CPU compositor
at <=1/255. Explicit `--release` runs measure 120 real pointer frames at each
scale, reporting UI time separately from GPU execution and screenshot readback.
The screenshot oracle excludes the offscreen harness's synthetic cursor triangle
and its stroke/AA bounds, and requires at least 120 unobstructed ink samples.
The timing sample uses a 48x48 SVG in a 128x128 document at zoom 1, inside an
1100x800-point app viewport; it is not a large-document performance gate.
The engine's separate real-GPU test compares the entire premultiplied frame with
the CPU compositor <=1/255, including gradient-filled curve edges. Neither has a no-adapter skip.

The scratch workspace under target/refvec/svg-import-build registers these hooks
without editing any shared source. Its checks are evidence for these fragments;
they do not establish that the actual branch already exposes an integrated UI.
Run the full-app acceptance again after 00 applies the real registrations.
