Replace only the Vector built-in data in toolsets.rs; leave Pixel ALL_TOOLS, presets, keys
and customization migration unchanged. Keep the existing canonical/custom-set APIs. Fold the
five returned sets into the existing catalog, not a separate list/store. All Tools includes
every executable ID once, even a future unknown ID (tail slot). Presets filter unavailable
IDs; an empty family vanishes. The existing `PathSelection`, `Crop`, `Type`, `CustomShape`,
`Repeat`, `Envelope` stay reachable as extra members of their nearest existing family.

Use `layout::GROUPS` as the exact 22 compact flyout families. Default = first available tool;
the active member replaces its family leader. Long press threshold = 350ms. The compiled
`fill_stroke_proxy::flyouts` implements the interaction (no fake tools); use it in 01's shell
or retain its established flyout UI and feed it the new groups. On choosing a Tool invoke
`persona::select_tool` so the old gesture is cancelled. Do not cache the availability list
in OnceLock: tools become available as their providers are wired.

`fill_stroke_proxy::icons::ICONS` has `(Tool ID, asset ID, colour bytes, mono bytes)` for all
58 existing reserved Vector entries plus new package IDs and proxy controls. It is the exact
01 icon override fragment. Move uses mouse-pointer-2 in Vector; Direct Selection uses
`direct-select`. Pixel keeps its existing icon IDs. New IDs use `vector-*` assets, preventing
collisions with raster Pencil, Eraser, Scissors/AI Cutout and Blend/Gradient.

Provider ID adapters are explicit: use the PascalCase shell IDs in GROUPS for the lower-case
feature enums (e.g. 34 rotate → Rotate, 40 blobBrush → BlobBrush, 32 object/node lasso →
VectorLasso, 41 vector warp → VectorWarp). Do not create raster fallback aliases. Callout
Ellipse is eligible only if 02 registers that separate variant; otherwise its icon is ready
and the flyout shows only Callout. No unimplemented niche tools are declared.

## Proxy host and lifecycle

Append transient `fill_stroke_proxy::State` to UiState with serde(skip), and use 35's existing
State (do not duplicate its draw mode). Under the **Vector** tools only:

```rust
fill_stroke_proxy::widget(ui, proxy, &mut app.session, &selected_ids, clip_compound_state)?;
```

Call `proxy.synchronize(&app.session, &selected_ids, persona == Persona::Vector)` every
frame before display/canvas routing, including hidden chrome. Escape/focus loss/persona or
document/selection changes cancel. Feed `proxy.preview` to the existing detached display-doc
provider before composing (only while fresh); release restores the ordinary committed doc.
Tool changes call `proxy.cancel`. Report EngineError via the existing localized status path.

X toggles active paint without a document edit; Shift+X swaps top visible fill/stroke paints
on *each* captured shape in one undo. Missing counterparts remain none. D sets white fill /
black stroke. Slash hides that paint kind's stack items without destroying their metadata.
Colour opens a captured six-digit hex editor; Apply is one 08 command, Cancel zero. Gradient
uses the renderer's standard opaque black/white linear gradient. Swatches show the current
shape's paint (gradient representative stop; none is a red slash), with the active swatch
in front. Stroke widths, brushes, profiles, arrows, blends and opacity survive swapping.
The proxy fits a 46px content column: two compact Swap/Default controls, three Colour/Gradient/None controls, and one current draw-mode icon. Tool flyouts and the draw-mode menu use egui Popup; Colour uses an egui editor window within the same offscreen/native app surface (no OS window). The proxy hosts 35's unmodified draw-mode widget in that menu, including Draw Inside enablement and cancellation. Paint buttons capture and produce detached preview on press, then commit that preview once on release; pointer release outside cancels.

The branch's package 08 currently uses NoProjection in its registered command. If the
selection has 11/17 variable widths/brushes, 00 must install those projection hooks in 08
before enhanced-paint acceptance; this proxy does not invent another renderer.
