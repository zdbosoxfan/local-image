# 40 — Blob Brush / vector Eraser integration

Engine, sweep and UI modules are compiled on this branch. Minimal append-only
registration adds `pub mod sweep`, `pub mod blob_eraser`, the UI path module declaration,
and `out.extend(blob_eraser::specs())` to compile/journal this new command slot. No
manifest, dependency, lock, catalogue, menu, prefs, router, or other package edits.
The engine command IDs are new here: `path.blob` / `path.eraseRegion` (journal=true),
`path.blobEraser.preview` (journal=false). Do not register them twice.

## Public API

```rust
use photocraft_engine::vector_packages::blob_eraser::{Capture, Mode, Options, Request, Prepared, Tip, sweep};
Capture::begin(&Session, Mode, Options) -> Result<Capture>
Capture::begin_with_color(&Session, Mode, Options, [f32;4]) -> Result<Capture>
Capture::validate(&self, &Session) -> Result<()>
prepare(&Session, &Request) -> Result<Prepared>
Prepared::capture(&self) -> &Capture
Prepared::commit(self, &mut Session) -> Result<serde_json::Value>
// Prepared: document: Arc<Document>, region: Path, layers: Vec<LayerId>, changed: bool
// Request: capture: Capture, samples: Vec<sweep::Sample>, rectangle: bool
// Sample: point: photocraft_geom::Point, pressure: f64 (0..1)
sweep::outline(&[sweep::Sample], Tip) -> Result<Path, String>
sweep::rectangle(Point, Point) -> Result<Path, String>
```

Capture freezes document ID/revision, eligible target IDs, selection/insertion sibling,
stroke colour and options. Targets include selected-group descendant shapes. With no
selection the Eraser captures all unlocked shapes. Text/symbols are excluded and indicated
by `Capture::excluded` / `EXCLUDED_TOOLTIP`. Explicit locked targets reject the entire
gesture before rendering. Targets are revalidated on preview and commit. All results
and bounds-limited caches are prepared before a single Session::edit; no-op UI strokes
dispatch no command, create no undo and no journal. Command callers should use preview's
`changed` before dispatching an edit if they also require no-op journal suppression.

Blob fill takes the captured stroke swatch. Same-colour, fill-only matching appearances
merge across the connected intersecting component. Merges remain within one parent and
exclude masks, effects, clipping and other differing appearance context. Keep Selected
controls the resulting selection. Merge Only with Selection limits candidates at press.
Eraser retains layer paint/metadata; filled connected outers are separate paths with their
holes, open curves are cut at V1 arrangement intersections with exact cubic subsegments.
Legacy/new live-shape and live-corner geometry is baked and its parametric metadata cleared.
Pressure modulation is diameter=size*(1-modulation+modulation*pressure).

## 00 — production app routing

UI module `photocraft_ui_egui::blob_eraser` exposes:

```rust
pub struct State { pub mode: Mode, pub options: Options, pub rope_length: f64, /* transient */ }
State::active(&self) -> bool
State::preview(&self) -> Option<&Prepared>
State::cancel(&mut self)
State::frame(&mut self, &Session, &egui::Context, selected: bool)
State::display_doc(&self, &Session) -> Option<(Arc<Document>, u64)>
State::pointer(&mut self, &mut Session, ToolEvent, egui::Modifiers) -> Result<()>
State::pointer_with_color(&mut self, &mut Session, ToolEvent, egui::Modifiers, [f32;4]) -> Result<()>
canvas_input_with_pressure(&mut State, &mut Session, &egui::Response, &ViewXform, f32, [f32;4]) -> Result<()>
context_bar(&mut egui::Ui, &mut State)
paint_overlay(&State, &egui::Painter, &ViewXform, egui::Pos2)
```

1. Add `pub blob_eraser: blob_eraser::State` to `PhotocraftApp`, initialized with Default.
   Add defaulted prefs for `Options` and `rope_length`, using the established tool-options
   store; load/save them. State deserializes `{}` and skips all gesture/preview caches.
2. In the normal tool frame, set mode from `Tool::BlobBrush` or `Tool::VectorEraser`, then
   call `frame(&session, ctx, matches!(tool, Tool::BlobBrush | Tool::VectorEraser))` EVERY
   frame, including after a tool/persona switch. This cancels stale/focus/Escape captures.
3. Route the existing captured Down/Move/Up ToolEvent stream to `pointer_with_color`,
   with current modifiers and the recovered tablet pressure. Supply package 46's current
   **stroke** swatch RGBA. The fallback `pointer` uses foreground for pre-proxy hosts.
   The small-host adapter is also available; use one input route, not both.
4. Route context bar and cursor painter for both variants. For Eraser the context bar
   gives the Alt rectangle instruction and text/symbol exclusion tooltip. Display errors
   through the existing tool error channel.
5. In `gpu_canvas`/CPU display document selection, include
   `blob_eraser.display_doc(&session)` in the same detached preview plane route used by
   Pencil/Brush. Use its generation as the preview revision; invalidate when cancellation
   clears it. Never assign its document to `Session::active_mut().doc`. Composite the
   entire affected stack so erasure also previews on existing shape caches.
6. The production dispatcher passes modifiers on every Move/release; Alt is not latched.
   The egui response adapter also reevaluates Alt changes without a pointer move. Cancel
   on pointer/focus loss; capture release outside the canvas.

requires RTX 5090/discrete/Vulkan/Rgba32Float and checks preview/release/undo GPU pixels.
Run it explicitly at the integration milestone, never accept a software-adapter skip.

```rust

```

release, region/Alt rectangle erasure, Escape and undo via actual GpuCanvas float texels
