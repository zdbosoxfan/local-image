## Capture / detached preview / release

These compiled helpers are available for package 28's existing `layer.vectorize` apply command; package 26 registers no competing command:

```rust
let capture = trace_cleanup::capture(session, &source_ids)?; // pointer/request begin
capture.check(session)?;                                   // document ID/revision + every target
let preview = trace_cleanup::prepare(session, &capture, &output, [roi_x, roi_y], cancel)?;
// Preview is detached: do not Session::edit, journal, or replace document caches.
let group_id = trace_cleanup::commit(session, preview, group_name, cancel)?; // release, one edit
```

`Capture` fields and `Prepared` children are private to prevent mutation of a validated preview. Every target is checked for existence, duplicates, Raster/Smart content and inherited pixel/all locks. Preparation preflights **all** geometry/counts before making sparse, bounds-clipped pc-vector caches. Commit checks document/revision and the complete captured target set again. Cancel/staleness/nonfinite/locked-set errors leave document, history and journal untouched. Package 28's public apply spec must remain `journal=true`; the helper itself uses one Session::edit. For Expand/Make Work Path, package 28 retains its output modes and can use the pure evaluator with its own equivalently guarded preparation/publication.
