## 00/08: additive native paint

Keep legacy `FillItem { paint: Fill }` wire/Rust APIs stable. Add an appearance paint item:

```rust
// pc-doc/src/vector_design/appearance.rs; existing serde default helpers are reusable.
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct MeshPoint {
    pub position: [f64; 2],
    #[serde(default)] pub handles: [[f64; 2]; 4], // right, left, down, up; offsets
    pub rgba: [f32; 4], // straight sRGB; alpha is multiplied by point opacity
    #[serde(default = "one")] pub opacity: f32,
}
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct GradientMesh {
    pub rows: usize, pub cols: usize, // patch counts; rows+1 × cols+1 points
    pub points: Vec<MeshPoint>,
    #[serde(default = "yes")] pub dither: bool,
    #[serde(default, skip_serializing_if = "is_zero_seed")] pub seed: u32,
}
fn is_zero_seed(seed: &u32) -> bool { *seed == 0 }
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct MeshFillItem {
    pub paint: GradientMesh,
    #[serde(default = "one", skip_serializing_if = "is_one")] pub opacity: f32,
    #[serde(default = "normal", skip_serializing_if = "is_normal")] pub blend: BlendMode,
    #[serde(default = "yes", skip_serializing_if = "is_true")] pub visible: bool,
}
// Add to AppearanceItem, retaining its existing kind/snake_case serde tagging:
Mesh(MeshFillItem),
```

## 09/14/21/23: scaled projection and file fallback

Scale both path and mesh by the same Affine, retaining global device origin and seed;
render into the supplied visible device clip, never the persistent 1x caches. 09's source exists here but its shared crate export is absent. 00/09 exports that module and installs
this function-only hook during normal startup (and the engine integration-test setup):

```rust
let _ = photocraft_engine::vector_packages::mesh::install_view_hooks(
    photocraft_engine::vector_packages::mesh::ViewHooks { project: project_mesh_view }
);
fn project_mesh_view(doc: &Document, scale: f64) -> photocraft_engine::Result<Document> {
    let mut cache = photocraft_compose::scaled_view::ProjectionCache::default();
    cache.project_at(doc, doc.bounds(), scale, &Default::default(), enhanced_projector)
        .map_err(|e| photocraft_engine::EngineError::Other(e.to_string()))
}
```

`enhanced_projector` is the unified 08/09 provider, preserving every fill/stroke, masks and
clipping, with mesh converted/scaled as above. Production should reuse its existing view
cache; the fresh cache shown here is sufficient for the independent parity fixture.
`mesh/gpu_tests.rs` asserts this hook is installed before its 1/2/4/8x checks; absence fails,
never silently substitutes a private scale evaluator. The function-only static hook stores
no document data.

File adapters use native `vector_design::exchange` data and the 08 renderer, never the
engine/UI. `CompiledMesh::render(format)` supplies clipped/bounded mesh-only pixels;
the full appearance renderer supplies the authoritative stack cache. Rasterize at export
scale through 09. `mesh_paint::raster_fallback_warning(&mut warnings, ExportFormat)` adds
one `VectorWarning { feature: "gradient_mesh", object: None, ... }` per export, aggregating
all mesh objects. Reuse the adapters' existing feature-key collectors.

- 21's `Writer::fallback`, Shape/Appearance match: visible `AppearanceItem::Mesh` requires
  raster fallback and `self.warn("gradient_mesh", "Gradient mesh paint was rasterized; mesh points lost editability.")`.
  `krilla::paint` 0.8.2 has no public type 6/7 shading writer. Keep the existing krilla image
  path; no hand-written PDF object injection. A future shading provider must preserve
  premultiplied linear-light colour and point alpha/dither before replacing fallback.
- 14's `Writer::raster_reason`: Mesh returns true and warns under the same feature key;
  use its bounded embedded PNG path and full stack projection.
- 23's `pc-io/src/vector_fallback.rs` appearance scanner: Mesh adds a new gradient-mesh
  loss to the existing aggregated collector and requires authoritative merged cache with
  the existing advanced fallback marker. Retain supported stroke proxies; do not advertise
