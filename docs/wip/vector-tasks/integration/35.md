## Engine API and commands

`photocraft_engine::vector_packages::clip_compound` exports:

```rust
Capture::begin(&Session, &[LayerId]) -> Result<Capture>
Capture::selected(&Session) -> Result<Capture>
Capture::params(&self) -> Result<serde_json::Value>
prepare(&Session, &Capture, &Action) -> Result<Prepared>
prepare_insert(&Session, &Capture, DrawMode, Option<LayerId>, Layer) -> Result<Prepared>
preview_draw(&Session, &DrawRequest) -> Result<Prepared>
clip_parent(&Document, LayerId) -> Option<LayerId>
```

`Prepared { document, selection, .. }` is detached, cancellable by dropping it. Every
commit reparses/prepares and checks the captured document ID, revision and entire set.
Engine edit commands are `journal=true`, select-only commands are `journal=false`.
Selection uses existing `DocState` fields, with no second selection store.
Limits: 256 input objects/released contours, 65,536 path nodes, coordinates within
1,000,000 pixels, the existing 100-group nesting limit, and 512 MiB aggregate prepared
shape caches. Rejections are atomic. Package 12's private curve adapter is temporarily
compiled from its one existing source with a narrowly justified duplicate-module lint
expectation; 00 can expose `path_text::curves::paths` and replace that bridge with a use.

| Command | JSON parameters | Vector accelerator |
|---|---|---|
| `object.clippingMask.make` | `{document,revision,layers:[id,…]}` | Ctrl+7 / Cmd+7 |
| `object.clippingMask.release` | same, exactly one clip group | Alt+Ctrl+7 / Alt+Cmd+7 |
| `object.clippingMask.editMask` | same, group or content IDs | none |
| `object.clippingMask.editContents` | same, group or content IDs | none |
| `object.compoundPath.make` | same, >=2 sibling shapes | Ctrl+8 / Cmd+8 |
| `object.compoundPath.release` | same, one compound shape | Alt+Shift+Ctrl+8 / Alt+Shift+Cmd+8 |
| `object.fillRule` | `{capture:{document,revision,layers},rule:"NonZero"|"EvenOdd"}` | none |
| `object.moveInside` | `{capture:{document,revision,layers},target:id}` | none |
| `object.moveOutside` | `{document,revision,layers}` | none |
| `object.draw.insert` | serialized `DrawRequest` | tool release |

`DrawRequest { capture, mode, target, layer, path, fill, stroke }`; mode strings are
`normal`, `behind`, `inside`; path is the **native serde Path**, not `path_json`.
Capture at Begin, and keep both target and new layer ID fixed through Preview/Commit.
An absent normal/behind target inserts at the root top/bottom respectively. 37 should
resolve isolation/insertion targeting before Begin and pass that explicit target.

Make Clip consumes the topmost selected path/text into the group's authoritative
`vector_mask`. Contents retain IDs/order/geometry/paint. Release splits the group and
reconstructs the top unpainted shape from the **current** mask, including later node
edits. Text becomes ordinary pc-text outlines on release. There is no retained painted
clip child to desynchronize from the mask, and no duplicate `vector.clip` mirror.
Draw Inside and Move Inside retain the selected object's appearance as the bottom child
of a masked group; subsequent contents append. Move Outside hoists selected siblings
above their immediate parent in paint order. Cycle, depth, lock and stale errors publish
no document, revision, pixels, history or journal changes.

Make Compound uses the bottom shape's appearance/compositing envelope, plain paths,
and a single native component (`Combine` first contour, `Join` following contours).
Native `Combine` components independently union; using Combine on every contour would
make the required even-odd ring impossible. Simple knots/handles stay lossless; ordered
PSD boolean operations and even-odd source shapes normalize through V1, corners project
through 06. Release produces one same-appearance shape per subpath. Inverted input needs
a bounded normalization provider; V1 returns NeedsClip rather than a false success.
Release Clipping refuses groups with additional group appearance/artboard/live/pixel-mask
semantics, rather than silently discarding those properties while ungrouping.

## UI hooks (00 / 01 / 37 / 46)

Compiled module: `photocraft_ui_egui::clip_compound`.
Add transient `pub clip_compound_state: clip_compound::State` to `PhotocraftApp`, Default
in its constructor. Persist only `Settings` (serde default Draw Normal) in the existing
prefs store. No new tool IDs: these are drawing modes and object commands.

```rust
draw_mode_widget(ui, &app.session, &mut app.clip_compound_state, |s| i18n::t(s).to_owned());
shortcuts(ctx, &mut app.session, &mut app.clip_compound_state, persona_is_vector);
context_menu(ui, &mut app.session, &mut app.clip_compound_state, |s| i18n::t(s).to_owned());
indicator(painter, &app.clip_compound_state, selected_target_screen_bounds);
```

Call shortcuts before Pixel/default dispatch **only** in Vector, so these accelerators
do not change Pixel shortcuts. Shift+D cycles Normal/Behind/Inside, skipping Inside
without one eligible target. Widget labels/tooltips and mode glyph requests for 46:
`Draw Normal` overlapping rectangles; `Draw Behind` rear rectangle; `Draw Inside`
rectangle inside dashed corners. These are requests for original icons, no brand assets.
Honor the shortcut function's `true` return by stopping further dispatch of that key;
it follows the existing `shortcut_dispatch::Focus` policy and matches event modifiers.
Menu locations: Object > Clipping Mask / Compound Path, Layers context menu;
Layer > Arrange > Move Inside/Outside; Fill Mode non-zero/even-odd in shape context bar.
UI `execute(session,state,Command)` captures IDs/revision, resolves Release from a selected
child to its nearest clip group, and resolves Move Inside to the immediate object above.
Surface `state.error` through the existing app error/status UI. A failed draw preview
cancels its capture and detached document, so release cannot commit an earlier valid path.

Draw tool integration (02/04/05/17 and existing vector_ui):

```rust
state.begin_draw(session, insertion_target_from_37, fill, stroke)?; // pointer-down
state.preview_draw(session, provider_document_space_path)?;       // pointer frames
state.commit_draw(session)?;                                     // release, one command
state.frame(session, persona_is_vector, focused, escape);         // each frame
state.cancel();                                                  // tool/document switch
```

When `state.preview` is Some and capture remains fresh, route it to the **existing**
CPU/GPU display-document lookup before persisted doc/cache lookup; include a monotonically
changing preview generation in the app's transient view cache key (the app/router owns
that key). Render only damaged regions, keep authoritative Session/history untouched.
On release/cancel invalidate the transient key and clear preview. Draw Inside commits
select the group, keeping subsequent strokes aimed at the same group. Edit Mask sets
`state.mask_target`; route that to existing `DirectSelection.target = Some(PathRef::Layer(id.0))`
and clear old node/segment selection. It addresses the group vector mask. Edit Contents
clears `mask_target` and selects the ordinary children.

Layers integration attaches to existing row responses, not a second production panel:

```rust
layers_begin(state);
// existing row loop, with Sense::click_and_drag():
layer_row(ui, response, layer_id, &session, state);
// after ALL rows, including when the pointer leaves the panel:
layers_end(ui, &mut session, state);
```

`layers_fragment` is the package's small kittest host. It is not a replacement panel.
Actual pointer drags preflight a detached Move Inside preview, highlight the destination,
then execute one command on release. Escape/focus loss/stale document cancels.

## Tests / integration gates

Compiled new tests use `clip35_` (engine and kittest). The ignored engine GPU test asserts
RTX 5090 / Vulkan / discrete / Rgba32Float, compares premultiplied pixels <=1/255 for
mixed raster/vector clip preview, commit, release and undo. It never skips for adapters.
Owner speed override means **do not execute it in this package job**.

The full production app source is supplied at
`crates/pc-ui-egui/src/vector_packages/clip_compound/app_gpu.rs`.
It intentionally requires the `PhotocraftApp.clip_compound_state` and real drawing/display
routes above. After wiring, register it in the existing serialized GPU test binary:

```rust
#[path = "../../src/vector_packages/clip_compound/app_gpu.rs"]
mod clip_compound;
```

It uses `crate::gpu_lock()` and egui_kittest offscreen eframe. It drags the real Rectangle
tool inside an ellipse, inspects live detached preview, reads the actual GPU app canvas,
checks atomic release/clip release/undo/Escape, and requires RTX 5090/Vulkan/discrete,
Rgba32Float and float canvas. No temporary app-document substitution is permitted.
Until registered after routing, this is a **missing integrated gate**, not a passing test.
No GPU/performance run or benchmark result is claimed. Export fixtures exercise the
already integrated 14/21/23 public hooks and `vector_design::exchange::ExportScope`.
