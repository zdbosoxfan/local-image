## Commands and captures

All edit commands are journal=true; the query/preview commands are journal=false:

```text
object.path.commit   {capture:{document:u64,revision:u64,layers:[u64]},action:Action}
object.path.preview  {capture,action} -> {original_points,new_points,detached:true}
object.expand        {capture,options:{object:true,fill:true,stroke:true},appearance:false}
object.expand.info   {capture,options,appearance} -> {enabled,reason}
object.pasteFront    {capture,clipboard:{native:[u8]}}
object.pasteBack     {capture,clipboard:{native:[u8]}}
```

`Action` is tagged with `kind`, snake_case:

```json
{"kind":"join","tolerance":0.000001}
{"kind":"average","axis":"both","anchors":[{"layer":123,"points":[[0,0],[0,1]]}]}
{"kind":"simplify","precision":80,"corner_angle":30}
{"kind":"add_anchors"}
{"kind":"remove_anchors","anchors":[{"layer":123,"points":[[0,1]]}]}
{"kind":"clean_up","stray_points":true,"unpainted":true,"empty_text":true}
{"kind":"divide_below"}
{"kind":"grid","rows":3,"columns":2,"row_gutter":10,"column_gutter":10,"guides":true}
```

Use the new captured wrapper for the Object menu; keep existing V1 IDs `path.join`,
`path.simplify`, `path.outlineStroke`, `path.offset` registered once. The new Join delegates to
V1 and additionally checks sibling paint/transparency compatibility. It preserves the first
captured ID. No unrelated scene objects disappear due to an invalid last target. Average
computes a global centroid across selected layers and translates handles. Precision 0–100
maps to document-space tolerance 5–0.01 pixels; corner threshold 0–180 degrees uses V1's
public simplify_with. Anchors are explicit [subpath,knot] coordinates from direct selection. Average/Remove address
base knots before corner projection; remaining corner references remap after removal.
Empty direct selection for Average means all anchors of the selected shapes; Remove requires
explicit anchors. Add uses de Casteljau midpoints; Remove uses V1's refit-preserving operation.

All captures check document/revision, disjoint IDs and inherited/descendant locks. Paste alone
allows an empty target list through `Capture::begin_paste`; it captures root insertion instead. Inputs and
outputs are bounded (256 roots, 65,536 knots per path, coordinates ±1e6, 4096 grid cells,
512 MiB aggregate prepared cache budget). Geometry preparation and rendering occur on a clone;
publication is one Session::edit. Cache bounds use CompiledAppearance ∩ document.
Grid output is a group of ordinary cells, with the source layer's transparency/masks once on
the outside and the source paint on each cell. Divide processes ordinary closed shape leaves
below the cutter in document paint order, preserves the target paint in a two-piece group,
and consumes the cutter. Expanding live ancestors first is required before dividing them.
Clean Up ignores non-shape/non-text targets; whitespace-only text counts as empty.

## Exact production hooks (00 ownership)

All functions are implemented under `photocraft_ui_egui::object_path::app_hooks`.
Bridge state lives in egui context data, not shared persisted UI fields.

1. In `PhotocraftApp::logic`, replace the normal shortcut call with:

```rust
if !crate::object_path::app_hooks::frame(self, ctx) {
    shortcuts::handle(self, ctx);
}
```

`frame` checks Vector persona + Compositing, cancels on tool/persona/module change, shows the
captured dialog, handles errors and consumes Vector J/F/B/C/Alt+J before Pixel dispatch.
Run 03's `direct_select::frame` first. In Direct Selection the hook uses 03's base-knot selections
(including additional curves) as the captured layer set, independently of the layer-panel set;
other tools ignore stale node selections.
It blocks underlying shortcuts while its dialog is open and yields to existing menus, foreign
modal dialogs, inline canvas text editing and other captured editing modes. Existing raster/OS clipboard stays
unchanged. The existing raw_input_hook clipboard normalization retains command key events.

2. In the shared Object menu, supply this fragment (all visible labels use host i18n):

```rust
crate::object_path::app_hooks::menu(app, ui, |label| crate::i18n::t(label).to_owned());
```

Show this fragment only in Vector persona + Compositing. Add the Object top-level menu if 46 has not done so yet. Path submenu and Expand/Expand
Appearance are supplied here. Both Expand entries disable with the exact owner/provider
failure reason. Outline Stroke routes to the existing V1 command for legacy strokes; advanced
strokes receive a reason to use Expand Appearance. Offset Path dialog delegates its detached
preview and commit to package 10 `constructive::Gesture` (Contour). No duplicate kernel.

3. In Edit (Vector persona, with no focused text field or inline canvas text editor), route Copy to
`crate::object_path::app_hooks::copy(app, ui.ctx())`; include:

```rust
crate::object_path::app_hooks::paste_menu(app, ui, |label| crate::i18n::t(label).to_owned());
```

Keyboard Ctrl/Cmd+C already routes through frame to the same vector clipboard. Clipboard is a
bounded native-codec snapshot (64 MiB compressed), preserving full layer trees, masks, effects,
patterns, live data and symbol masters. Paste duplicates IDs, remaps symbol resources and
preserves coordinates/paint order. It inserts immediately above the top selected sibling or
below the bottom selected sibling. Selected destination targets must share a parent. With no selected objects, Front/Back inserts
at the root's top/bottom, including an empty document. Cross-canvas,
color, DPI, global-light or text-style context rebaking and conflicting pattern resources return a reason
until the common projection owner supplies them; they never flatten to pixels silently.

4. Pass `ctx: &egui::Context` into `canvas::display_doc` (the current app has no stored
Context field), and at its START, before other preview providers:

```rust
if let Some(shown) = crate::object_path::app_hooks::display(app, ctx, idx) {
    return shown;
}
```

Exact host signature becomes
`fn display_doc(app: &mut PhotocraftApp, ctx: &egui::Context, idx: usize) -> (Arc<Document>, u64)`.
`navigator_texture` and `ensure_texture` already receive `ctx`: pass it to their display calls.
Also add `ctx: &egui::Context` to `ensure_gpu`, pass it from the existing `canvas_view` call (`ui.ctx()` supplies the Context),
and forward it into display_doc. Existing canvas test calls supply their harness Context.
`display(app, &egui::Context, idx)` is the exact package signature. The preview is a detached Arc with
a unique generation key, valid only for captured identity/revision/locks. No document swap,
history record or journal entry happens on a slider frame. Cancel/close/Escape/focus loss/stale
targets drop it. Renderer 09 must consume this returned document in the actual GPU and CPU
canvas and Navigator, not just an independent preview bitmap.

## Expansion owners and remaining provider boundaries

`expand::prepare(&Session,&Request)->Result<Prepared>` and
`expand::disabled_reason(&Session,&Request)->Option<String>` are public. Appearance expansion
creates one ordinary child path per paint, bottom to top (including invisible paints), and
keeps parent blend/opacity/masks/effects once. Object/Fill/Stroke options are independent;
unchecked ordinary strokes stay strokes. Live shape generation (02) precedes corner projection
(06). Width/brush outlines use their public providers (11/17). Repeat uses 19's public projection
and fresh persistent child IDs; symbol uses 15's public expansion/preparation. Path text uses
12's public `type.path.convert` command in a detached Session, discarding that session's
history/journal before one publication in the real session.

`expand::Projection` is the public StrokeProjection combining 11/17 for ordinary appearance
preview caches. Plain filled paths retain native gradient/pattern fills; stroke gradient/pattern
conversion needs a paint-frame bake, and unsupported arrow/dash/gradient modes return a reason.
Fill does not invent a mesh/solid gradient approximation absent the owning provider.

18 and 20 have empty engine slots in this baseline, and no blend/envelope evaluator/API.
Their live variants therefore disable with explicit owner 18/20 reasons. 42 and 45 have neither
active shared variants nor public expand APIs in this branch; register those owner variants
and providers here when they land. Vector crop/clip projection (35), advanced content in
symbol/repeat preparation (08/09), and arbitrary paint-coordinate baking remain named provider
boundaries, as the existing owners already report. Do not erase live metadata to fake expansion.
Selected live shapes/corners require Object when expanding paint; otherwise the dialog explains
that requirement. File import/export adapters continue to use vector_design::exchange and the
owner data projections; this engine/UI module is not a new file-format dependency.

## Tests and integration gates

New engine/UI tests use filter `object36_`; no aggregate test-binary wiring is needed for these
compiled nested modules. GPU tests are compiled and ignored, explicitly pending production
hook integration and RTX execution:

```text
object36_gpu_expand_four_paints_before_preview_release_undo
object36_full_app_gpu_simplify_slider_live_cancel_release_one_undo
object36_full_app_gpu_expand_appearance_pixel_parity_menu_undo
```

They require RTX 5090/Vulkan/discrete and Rgba32Float, with required float canvas format in the
app tests. No unavailable/software adapter is counted as success. Full-app tests use actual
PhotocraftApp menu clicks, slider pointer frames, GPU canvas texel readback, release/Cancel/undo
and premultiplied max diff<=1/255. Missing production hooks fail when the ignored gate is run.
Coordinator must run these after hooks land; package 36 does not claim integrated acceptance
from its isolated widget tests or prohibited GPU execution. See the report for exact outcomes.
