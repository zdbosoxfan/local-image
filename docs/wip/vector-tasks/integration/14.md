## Enhanced projection bridge (08/12/15/live + 00)

`export::Projection::layer(&Document, &Layer) -> Result<Option<Layer>>` supplies one
ordinary detached replacement layer, retaining the compositing envelope and clearing
all evaluated metadata. Exports must receive the SAME geometry/cache projection as
display. Missing corners/path-text/live/pattern/brush/width providers return an
explicit dependency error; no empty-path or stale-cache success is advertised.
Generated design-shape Path remains authoritative. Native multi-paint stacks are
written directly; unsupported per-item blend/raster appearance needs its authoritative
merged cache from 08. Do not introduce a parallel SVG geometry evaluator.

Install once with `svg_export::install_provider(Provider)`; signature:

```rust
type Provider = fn(
    &Document, &ExportScope, &ExportOptions, &mut ExportContext<'_>
) -> photocraft_svg::export::Result<ExportedVector>;
```

The provider builds `ExportContext { cancelled, projection: Some(&provider), text }`
and delegates to `export_with`. Font engine is supplied by the process's existing
pc-text database; default pure-adapter export uses bundled fonts only.
