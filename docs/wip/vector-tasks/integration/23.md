This is an intentional raster fallback in Local Image after PSD reopen: the
editable advanced feature was lost at export. Supported `vmsk/vsms`, fill and
`vstk/vogk` proxy blocks remain in `psd_blocks` for unchanged PSD re-export and
external consumers. Reopening as an ordinary editable shape would split/redraw
its mirrored stroke over the already merged cache; generating ordinary `TySh`
for path text would similarly advertise unrelated editable text. This hook
avoids both, without inventing persisted editable metadata or changing the
legacy Photoshop corpus path. The marker's proxy flag distinguishes a shape's
proxy path from a type/symbol layer's ordinary user vector mask, which must
still apply once. Pixel edits invalidate editable proxy blocks using the marker's cache
fingerprint; the refreshed rendering marker retains blending behavior. Moves
translate its relative effect frame with the cache. Layer-level compositing edits
retain unchanged proxies. A separate user vector mask on an advanced shape is
baked through the native combined-mask renderer, because the PSD vector-mask
slot is occupied by the shape proxy; this loss is included in the notice. Pixel
masks stay independent. User vector masks on cached type/symbol layers stay editable.

`liVF` is private/versioned, strict-length checked (80 bytes), with a rendering
role byte (0=raster/symbol, 1=shape, 2=path text), a shape-proxy flag, BLAKE3
cache fingerprint and relative ordinary-effect paint frame. It contains no native advanced-feature data.
Unknown/truncated versions never trigger fallback. Layer masks/effects/blend,
opacity/visibility/clipping and original IDs use the existing PSD machinery.
The exported proxy fill/stroke uses **08's mirror_legacy**, bottom→top with hidden
items ignored and unsupported translucent pattern fill skipped. `Some(empty)`
disables paint, `None` retains legacy behavior. Cached pixels are clipped before
encoding/hash, never re-rendered from that proxy.

## Required compositor activation (00)

Reopening as raster must also retain **pixel compositing behavior**. Native type
uses the current text blending gamma; native shape stroke effects use vector
distance/coverage rules. Losing those when changing content kind breaks pixel
parity even when every channel and effect descriptor round-trips exactly. The
real-app test found this: unhooked native/reopened max .599215686 (stroke effect
fixture); without that stroke effect, path text over white still differed by
.155005217. Transparent-background cache tests alone cannot catch this.

Add the following to `pc-compose/src/lib.rs` (or move the strict decoder to a
00-owned shared doc module and call it from both IO and compose; compose must
not depend on IO):

```rust
/// Versioned PSD cache rendering role. No editable native feature is reconstructed.
pub fn psd_fallback_kind(layer: &Layer) -> Option<u8> {
    let (_, data) = layer.psd_blocks.iter().find(|(k, _)| k == b"liVF")?;
    const PREFIX: &[u8] = b"Local Image vector cache\0\0\0\0\x01\0";
    if data.len() != PREFIX.len() + 50 || !data.starts_with(PREFIX) || data[PREFIX.len()] > 2 { return None; }
    let kind = data[PREFIX.len()];
    let frame: [i32; 4] = std::array::from_fn(|k| {
        let i = PREFIX.len() + 34 + k * 4;
        i32::from_be_bytes([data[i], data[i+1], data[i+2], data[i+3]])
    });
    (data[PREFIX.len()+1] <= u8::from(kind == 1)
        && frame.iter().all(|v| v.unsigned_abs() <= 2_000_000)
        && frame[2] >= frame[0] && frame[3] >= frame[1]
        && (kind == 1 || frame == [0; 4])).then_some(kind)
}
/// Relative frame keeps ordinary gradient/pattern effects stable through Move.
pub fn psd_fallback_paint_bounds(layer: &Layer) -> Option<Rect> {
    if psd_fallback_kind(layer) != Some(1) { return None; }
    let (_, data) = layer.psd_blocks.iter().find(|(k, _)| k == b"liVF")?;
    let f: [i32; 4] = std::array::from_fn(|k| {
        let i = 64 + k * 4;
        i32::from_be_bytes([data[i], data[i+1], data[i+2], data[i+3]])
    });
    if f == [0; 4] { return None; }
    let b = layer.surface()?.content_bounds();
    Some(Rect::new(b.x0.checked_add(f[0])?, b.y0.checked_add(f[1])?, b.x0.checked_add(f[2])?, b.y0.checked_add(f[3])?))
}
/// Cached shape pixels retain the native shape's ordinary stroke-effect behavior.
pub fn vector_effects(layer: &Layer) -> bool {
    matches!(layer.content, LayerContent::Shape(_)) || psd_fallback_kind(layer) == Some(1)
}
```

In `paint_bounds`, return `psd_fallback_paint_bounds(layer)` from the non-shape
branch instead of `None`. This preserves gradient/pattern alignment, including
after Move. Change `text_gamma`'s condition to:

```rust

} else { 1.0 }
```

`pc-gpu/src/plan.rs` use `photocraft_compose::vector_effects(layer) && !outline`
for the `vector_shape` condition. GPU text gamma already uses compose's function.
This preserves native rendering rules rather than re-splitting the PSD mirror.
The probe applies **exactly these substitutions** on private copies only.

Retain the marker on unchanged raster re-export. Pixel edits drop stale proxy descriptors and refresh the pixel-rendering marker
through IO's hash guard. A future dedicated raster-conversion

## Common projection / missing feature providers (18–20 and crop owner)

```rust
pub trait Projection {
    fn layer(&self, document: &Document, layer: &Layer)
        -> Result<Option<Layer>, String>;
}
```

Use the **same provider as native display**. It returns ordinary detached layers
or a merged raster, preserves ID/compositing envelope, clears evaluated live/crop
metadata, validates source numeric parameters and supplies current caches. A
shape/type/symbol with a missing cache is an error. A live group has no shared
cache field: no provider means an explicit error, not exporting its original
children while claiming evaluated live pixels. 23 does not implement 18–20's
algorithms or add data fields. Width/profile/brush caches are consumed without
re-evaluation; their named providers remain necessary for native pixel acceptance.

`export(..., Some(provider))` returns original structured losses even after
projection; callers present them once. The normal save service needs the common
provider installed in its existing application export bridge after 18–20 land.
Do not install a format-only geometry implementation or silently use stale caches.
