# Package 44 integration handoff

Owned modules are compiled using append-only registrations. No core menu/router,
command aggregate, persistence schema, manifest/lock or catalogue was edited.
Current package tests cover the real widgets; full-app source below requires these
production callsites. Do not mark integrated acceptance passed before applying them.

## Engine query registration (00)

Append `out.extend(measure::specs());` in
`pc-engine/src/vector_packages.rs::specs`. Two commands:
`vector.measure.distance`, `vector.measure.area`, both `journal=false`.
Request: `{capture:{document:<u64>,revision:<u64>,layers:[<u64>]},a:[x,y],b:[x,y],units?:Pixels|Points|Millimeters|Inches,scale?:{factor},hovered?:[layer,[x,y]],perimeterMode?:FullEdges|CuspedSegments}`.
Area requires capture.layers; distance requires a/b. Responses contain numeric
DesignUnits values: distance/angle/dx/dy or area/includingHoles/perimeter/segment.
Captures reject stale/missing/duplicate targets, but locked objects are measurable.

## Tool registry (01/46) and canvas (00)

- IDs `vectorMeasure` / `area`; labels `Measure` / `Area`; family Vector;
  no default standalone shortcut (Eyedropper flyout, cycle I, per 46).
- Icons: existing `ruler` for vectorMeasure; 46 supplies hatched area/ruler icon.
  Pixel `Ruler` tool remains unchanged, including ID, shortcuts and dispatch.
- New Tool variants `VectorMeasure`, `Area` map to those distinct IDs.
- On activation **after selecting the new app Tool**, call
  `measure::activate(app, ctx, measure::Mode::Measure|Area)`.
- Each app frame before dispatch: `measure::frame(app, ctx)`; call even when the
  canvas is hidden so focus/persona/module/tool changes cancel capture.
- In the active canvas, after painting document layers and before legacy tool input,
  call `measure::route(app, ui, idx, &xf, content_rect)`. True consumes tool input;
  document canvas paint still occurs. It paints clipped transient egui overlays only.
  No `mark_dirty`, cache build, Session::edit or journal for measurement.
- Tool options call `measure::options(ui, &mut bridge.state, doc, revision,
  selected_artboard, effective_scale, |s| i18n::t(s).to_owned())`. The state is held
  in egui temporary context data under `Id::new("vector-measure-44")`; use
  `measure::bridge(ctx)` and `ctx.data_mut(|d| d.insert_temp(Id::new("vector-measure-44"), bridge))`
  when publishing options. Returned ScaleEdit must be committed through the setter below.
- `State::input(Response, Input)` is also public for the canvas provider to inject
  the actual 07 Manager settings. Current route uses `Bridge.settings` (07 defaults with curves
  enabled) and V1 Geometry supplied directly; update that field from the global
  snapping manager at the production options/route hook.
- View transform freezes at press; release samples current Shift/Ctrl and raw endpoint.
  Escape/focus loss/stale capture restores previous completed line, tool change
  drops drag. Readings are temporary, never document/settings/export/print data.

## Optional scale data and persistence (00-owned)

No field is present in the current model. Add `Option<DrawingScale>` to Document and
Artboard (`#[serde(default, skip_serializing_if="Option::is_none")]` in native mirrors),
using a **data-layer** equivalent of `{factor:f64}`. Keep the engine-owned type as
an adapter or re-export the shared type after integration; do not make pc-doc depend
on pc-engine. Absence=1:1; artboard override takes precedence over document scale.
Do not include measurement lines/readings in persistence. Validate factor 1e-6..=1e6.
All native construction/copy/migration paths should default/round-trip the optional
field. No format bump is necessary for an optional field.

Before route/options, call `measure::set_scale(ctx, effective_scale)` to supply it.
`DrawingScale::assign(raw_pixels, real_length, units, dpi)` handles known-distance
assignment; raw pixels avoid applying scale twice. Area uses factor squared.
`ScaleEdit {capture, artboard:Option<LayerId>, scale}.commit(session, setter)` checks
revision, targets, artboard kind and locks, then executes one metadata-only
Session::edit. Setter signature:
`FnOnce(&mut Document, Option<LayerId>, DrawingScale) -> photocraft_engine::Result<()>`.
Setter updates only requested document/artboard field; no raster cache is affected.
Register `vector.measure.setScale` journal=true only once those fields exist; do
not advertise a fake persisted command before the provider lands. The prepared
request provides finite bounded ratio input and Assign UI now.

## Geometry/selection limits

V1, 07 and 16 are integrated and reused, not duplicated. Corners project through
06. Measurements sum selected shape objects and group descendants without counting
selected ancestor+child twice. Hidden shapes do not hover, explicitly selected
hidden shapes can be measured. Open fills use V1's implicit straight closure for area and
report their actual curve length without the invisible closing edge. Inverted unbounded fills return V1 NeedsClip; unsupported
text/symbol/live-group selection errors name the geometry provider rather than
reporting empty success. Future shared feature projection should feed vector paths
for those types. Analytic live circle lengths require matching authoritative paths.
