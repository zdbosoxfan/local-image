Registered commands `vector.envelope.set` / `.expand` are journaled; `.preview`
is non-journaled. All accept the same captured request:

```rust
Commit { document: u64, revision: u64, edits: Vec<Edit> }
Edit { group: LayerId, sources: Vec<LayerId>, spec: EnvelopeSpec }
```

`sources` is the ordered complete descendant set including the group itself.
Obtain it with `Gesture::begin`; never reconstruct a subset in the router. Set
stores live metadata while retaining native shape paths, text runs and source
caches. Prepared display caches are transient; consumers MUST project live
metadata. Expand publishes ordinary projected shape/group children in one edit,
allocates real native IDs for synthetic outline children and clears the live spec.

The engine already uses `pub use photocraft_vecfx::envelope as geometry;` and
its minimal `photocraft-vecfx.workspace = true` consumer registration. The pure
crate uses the already-pinned kurbo dependency directly. This is necessary new-crate
registration under the task override; no new registry package is introduced.

## Shared native schema defect discovered by the roundtrip test

`envelope_engine_live_source_edits_reproject_and_native_roundtrip` currently fails
in `photocraft_format::load_from_bytes`: `unknown variant warp, expected blend,
repeat, envelope`. The existing shared `LiveGroup` and `EnvelopeSpec` both use an
internally tagged `kind`. The native loader parses into a JSON value, which retains
the inner `kind: warp` and loses the outer `kind: envelope`. Repeat has the same
collision. This is a shared schema fix for 00, not an evaluator failure; the failing
test is retained and is not counted as a successful native persistence gate.

00 should replace only `LiveGroup`'s serde derives/attribute in
`pc-doc/src/vector_design/live.rs`, keeping its public tuple variants, with the
following wire adapter. This preserves the established flat Blend wire shape and
accepts old flattened Envelope/Repeat metadata after native JSON-value parsing.
New Envelope/Repeat values use a separate `spec` field. No manifest-version bump
or public Rust API change is needed.

```rust
#[derive(Clone, Debug, PartialEq)]
pub enum LiveGroup {
    Blend(BlendSpec),
    Repeat(RepeatSpec),
    Envelope(EnvelopeSpec),
}

#[derive(Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
enum LiveGroupWire {
    Blend(BlendSpec),
    Repeat { spec: RepeatSpec },
    Envelope { spec: EnvelopeSpec },
}

impl Serialize for LiveGroup {
    fn serialize<S: serde::Serializer>(&self, serializer: S) -> Result<S::Ok, S::Error> {
        match self {
            Self::Blend(spec) => LiveGroupWire::Blend(spec.clone()),
            Self::Repeat(spec) => LiveGroupWire::Repeat { spec: spec.clone() },
            Self::Envelope(spec) => LiveGroupWire::Envelope { spec: spec.clone() },
        }.serialize(serializer)
    }
}

impl<'de> Deserialize<'de> for LiveGroup {
    fn deserialize<D: serde::Deserializer<'de>>(deserializer: D) -> Result<Self, D::Error> {
        #[derive(Deserialize)]
        #[serde(untagged)]
        enum ReadWire {
            Current(LiveGroupWire),
            LegacyEnvelope(EnvelopeSpec),
            LegacyRepeat(RepeatSpec),
        }
        Ok(match ReadWire::deserialize(deserializer)? {
            ReadWire::Current(LiveGroupWire::Blend(spec)) => Self::Blend(spec),
            ReadWire::Current(LiveGroupWire::Repeat { spec }) => Self::Repeat(spec),
            ReadWire::Current(LiveGroupWire::Envelope { spec }) => Self::Envelope(spec),
            ReadWire::LegacyEnvelope(spec) => Self::Envelope(spec),
            ReadWire::LegacyRepeat(spec) => Self::Repeat(spec),
        })
    }
}
```

After applying it, rerun the one failing native roundtrip test and add pc-doc wire
roundtrip tests for all three LiveGroup families plus old flat Blend, `kind: warp`
and `kind: grid` inputs. Direct JSON containing duplicate `kind` keys is malformed;
the legacy compatibility above covers the native loader's value representation.

## Production UI routing (00 / 01)

The compiled UI module is `photocraft_ui_egui::envelope`:

```rust
pub envelope_state: crate::envelope::State, // transient PhotocraftApp field
// initializer: envelope_state: Default::default(),
```

- Menu: Object > Envelope > Warp / Mesh / Make with Top Object / Expand. Target
  an existing selected group. Group creation/reparenting remains the established
  group command's responsibility; do not create a second layer tree.
- Set the current group: `app.envelope_state.set_target(Option<LayerId>)`. A
  selection change cancels a pending gesture. Enable for editable group sources;
  engine preflight is authoritative.
- Lifecycle BEFORE options/input/display each frame:
  `state.lifecycle(&session, envelope_active, ctx.input(|i| i.focused),
  ctx.input(|i| i.key_pressed(egui::Key::Escape)))`.
  Persona/tool/document switch and focus loss cancel, never auto-apply.
- Options: `state.context_bar(ui, &mut app.session)`. Numerical controls and style
  choices make detached previews; Apply commits once; Cancel drops the capture.
- At the main canvas response and its current `ViewXform`:
  `state.canvas_input(&mut app.session, &response, &xf)` before other canvas tools.
  While `state.is_dragging()`, consume the gesture so Move/painting cannot also run.
  Paint `state.draw_overlay(&app.session, &painter, &xf)` after the canvas.
  View transform is captured on press, including flip; Shift is sampled per frame.
- In `canvas::display_doc`, BEFORE raw committed-document fallback:

```rust
match app.envelope_state.display_for_document(&app.session, idx) {
    Ok(Some(shown)) => return shown,
    Ok(None) => {},
    Err(error) => { app.ui.status = error; /* use the normal error UI */ }
}
```

  Propagate projection failure; do not label a raw-source fallback as successful
  enhanced rendering. Use this same display document in Navigator and the 09
  scaled CPU/GPU view provider. Native reload, source shape/type edits and undo
  invalidate via revision. Font/paint-generation changes without a revision must
  call `state.invalidate_projection()`.
- Top-object selection supplies a detached path through
  `state.set_top_object(&session, path) -> Result<(), String>`. The evaluator
  chooses the largest closed outline and partitions it at four ordered corners.
  Four-sided cubic frames preserve their exact boundaries. Other outlines use
  bounded flattening at min(0.005px, fitting tolerance/8). The API retains the chosen object's source layer; removing
  or reparenting the top object is a separate explicit command, not a hidden edit.
- Current paint semantics: existing appearance is rendered AFTER geometry warp.
  This does not promise distortion of stroke width, gradient coordinates or
  pattern tiles. No unsupported “distort appearance” toggles are exposed.

## 08 / 12 / 09 and formats

Legacy/native shape, live-shape and corner paths use their existing providers.
Type and path type use pc-text's existing outlines, including run colours,
synthetic bold, decoration paths and editable original text. Appearance uses
`pc-vector::appearance::CompiledAppearance`; unsupported brush/width projections
fail with its named provider error. No extra shaper or rasterizer is introduced.

Source raster/vector masks and vector clips and nested other live groups need the unified projection
provider and currently return explicit errors. Parent groups and artboard clipping
remain in the normal compositor. Per-set cache allocation is capped at 256 MiB;
all geometry evaluates before rendering and publication.

File adapters must depend on `photocraft-vecfx` and use the pure evaluator inside
the existing `vector_design::exchange` ImportedScene/ExportedVector boundary.
They must not depend on the engine/UI projection. 00 wires this pure evaluator
into the common exchange projection traversal, with the same text/appearance
providers; this package does not edit other adapters' files.

## GPU and acceptance tests supplied

- `pc-engine/src/vector_packages/envelope/gpu_tests.rs`: strict RTX 5090 / Vulkan /
  discrete / Rgba32Float, warped path+text detached preview and committed projection
  against CPU compositor, premultiplied max diff <= 1/255.
- `pc-ui-egui/src/vector_packages/envelope/gpu_tests.rs`: offscreen full app with a
  package-owned input/display host, real mesh pointer down/move/cancel/release,
  warped text preview/release, CPU app canvas vs GPU app canvas byte diff <= 1.
  Host injects the detached display document only during an app frame and restores
  the original source Arc/revision; it is not production menu/router registration.

Both are compiled ignored integration gates with hardware failures asserted,
never silently skipped adapters. The latest speed rules forbid executing them in
this job. After production routing, 00 should replace the test-only injection
with `app.envelope_state` and exercise the actual menu/tool entrypoints before
calling integrated acceptance complete. No performance claims are made.
