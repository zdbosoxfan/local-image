## Shared gate API (compiled on this branch)

```rust
photocraft_testkit::vector_geometry::{
    Thresholds, Scores, Outcome, CorpusSummary, compare_regions, check_ratchet
}
compare_regions(actual: &[Path], reference: &[Path], view: Affine, rect: Rect)
    -> Result<Scores, String>;
check_ratchet(cases: &[(String, Outcome)], ratchet: &[(String, String)], minimum_pass: f64)
    -> Result<CorpusSummary, String>;
```

Region interiors must be disjoint and contours already resolved. The API reuses existing
Green area, nearest-point Hausdorff, independent exact native coverage, node-count and
crossing metrics. It rejects nonfinite/singular views and unbounded raster allocations.
MissingReference is not eligible for a geometry ratchet. Defaults: relative area<=0.001,
Hausdorff<=0.05 document px, 8x IoU>=0.999, node ratio<=1.5, no crossings. Corpus minimum
pass rate is 0.95. Unknown/duplicate/blank/stale entries fail; ratchets only shrink.
