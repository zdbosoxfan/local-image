Own GPL-3.0-or-later synthetic fixtures are generated by tests, deterministically offline:

| Test input | Parameters | Independent oracle |
|---|---|---|
| Circles | 241 points incl. seam; radii 10/50/100; center 150,150; tolerance 1.5 px | dense Bernstein evaluation vs polyline symmetric Hausdorff, strict crossings, <=8 nodes |
| Corner/sparse/sine strokes | tolerance 0.5; straight/90-degree/sparse zigzag/sine cases | independent point-to-line distances, preserved endpoints, crossing counts |
| Spiral / flat ellipse / jitter | expanding 1.8-turn spiral; ellipse radii 100/3; monotone sine plus 0.4 px jitter; tol 0.5, smoothness 1 | independent symmetric Hausdorff and crossings |
| 256 sine regressions | seeds 0..255 vary radius and smoothness; 49 samples; tol 0.5 | repeated deterministic paths, independent symmetric distances/crossings |
| Rope/window | rope 5, 3-4-5 geometry; window 3 with known arithmetic mean | explicit coordinates/pressure, cancel/restart and endpoint drain |
| Sculpt/continue | own open/closed compound paths, wrapping intervals, interior boundaries on the same cubic | exact outside anchors/components, independent Bernstein subcurve evaluation, native document bytes after undo |
| UI gestures | egui_kittest real press/moves/release, modifiers, clicking options, typing tolerance | session revision/journal/path and cancellation |
| GPU preview | own circle over solid background; full-app synthetic freehand on 240x160 | RTX 5090/Vulkan/discrete/Rgba32Float assertions; premultiplied max diff <=1/255 |

The full-app screenshot parity gate uses the existing in-memory preference to hide the
contextual task bar, which otherwise covers the canvas only after committing a selected shape.
It sends PointerGone before pixel captures because kittest paints a synthetic cursor in its
screenshots. Gesture frames, compositor callbacks, GPU submission/readback and release remain
actual app execution. The standalone float gate validates all outputs are finite before the
premultiplied comparison. Optional PENCIL_DIAGNOSTIC_DIR saves full harness frames under a
caller-specified directory for investigating failures (the recorded run used this worktree's target/).
The full UI regression suite also uses its existing repository plug-in fixture
`crates/pc-plugins/tests/fixtures/invert.wasm`; the scratch registration links that sibling
read-only so the unchanged baseline plug-in test can resolve its manifest-relative path.

Native fitting adds a convex-hull subdivision certificate against the source polyline to
reject between-sample excursions. Rope/window stabilization and exact Sculpt interval rules
are Local Image implementations: the pinned Pencil did not implement those required behaviors.
Tolerance applies after stabilization; raw tablet motion is intentionally filtered. Smoothing
movement is capped to one quarter of tolerance. Pressure is retained, without brush rendering.

Missing external/proprietary tablet captures and coordinator manual tablet QA are not passed
fixture gates. No Inkscape fixture/competitor output is represented as present or validated.
