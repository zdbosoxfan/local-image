# Small DeepSeek test/fixture jobs

`deepseek.tsv` uses package (Cargo package name), crate directory, Rust module name and exclusively owned module file. New internal packages use these exact names when registered by 00. Wait for the named package's public API before queuing its rows. These jobs never implement feature algorithms or modify shared files. Provide test-binary registration as an integration fragment to 00. Fixtures are original, deterministic, offline and <50 KB each, with GPL-3.0-or-later source records. Run the named tests, then the changed crate's required final checks once; use all the Rules in any numbered task. Do not commit.
