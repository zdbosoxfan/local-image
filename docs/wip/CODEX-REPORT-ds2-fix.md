Photoshop resources are filtered according to the [Adobe file format specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/) to keep IPTC/ICC/XMP while discarding stale previews and layer bookkeeping. The MaxPool default follows the [ONNX operator specification](https://onnx.ai/onnx/operators/onnx__MaxPool.html). Windows replacement semantics follow the [Rust fs::rename contract](https://doc.rust-lang.org/std/fs/fn.rename.html). The harness limit verdict follows the checked-in dependency source `egui_kittest-0.36.2/src/lib.rs`: `run_steps` calls `step` directly; the settling loop alone checks `max_steps`.

Restoration admission rechecks the resolved backend path and pinned bytes immediately before submission. ComfyUI core still opens a filename itself; preventing a privileged local actor from swapping bytes after admission would require backend cooperation or an immutable backend model store, outside this minimal repair. A model bundle interrupted by an I/O error can retain verified members already published; readiness requires every member and retry repairs it. These limits are documented rather than silently weakening verification or deleting previously installed models.
