# V2 interface captures

These three PNGs were supplied by the project owner on 16 October 2026 from the
installed Apple Silicon build of Local Image **2.0.0-alpha.1**, commit
`e345ce988641fe7cba47c07b7f67120c181e7f17`.
They are actual application captures, copied without retouching, resizing or
additional cropping. The Generate panel was already cropped in the supplied file.
Original filenames, dimensions and SHA-256 hashes are recorded in
[manifest.json](manifest.json).

- **compositing.png:** Storm Lighthouse in Compositing as one Develop smart layer.
- **library.png:** a nine-image demo catalog.
- **generate.png:** the native Generate panel controls; this does not show a
  completed generation or confirm a live server connection.

## Images displayed inside the app

The illustrations are existing Local Image example exports. Their models,
prompts, seeds and file hashes are recorded in the
[example manifest](../examples/manifest.json). These examples were originally
produced during Local Image 0.7 model validation and were imported into V2 for
this interface demonstration. No new large-model generation was performed for
these captures.

The photographic example is the public **Canon EOS R sample 4515** from
[raw.pixls.us](https://raw.pixls.us/), distributed by that collection under CC0:
[original CR3](https://raw.pixls.us/getfile.php/4515/nice/Canon%20-%20EOS%20R%20-%203:2.CR3).
Its source SHA-256 is
`89bd55532b0cceb5efa360e97827ba35c2076bce0de4675f3a4413a883dac880`.
The RAW itself is not bundled in this screenshot set.
